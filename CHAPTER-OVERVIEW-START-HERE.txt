===================================================
ระบบกลางรองรับแล้วในไฟล์โครงการนี้ ต้อง Commit/Push และรอ Actions ผ่านก่อนใช้บนเว็บจริง
ไม่มีการแก้ Firebase ไม่มีการบันทึกคะแนน และไม่เรียก AI
ไม่ได้เพิ่มเนื้อหาหรือเชื่อมบทกรด–เบสแทนครูในรอบนี้

ตัวเปิด HTML กลางไม่ได้ผูกกับชั้น 2
----------------------------------
เมนูเดิมยังอยู่ ปุ่ม HTML เปิดหน้าต่างเพิ่ม ไม่แทนที่เมนู และไม่เปลี่ยน HTML เป็น Quiz
ใช้ได้ในหน้าเลือกบท เมนูเรื่องย่อย เมนูเครื่องมือ และภายในหน้าต่างอ่าน HTML/เครื่องมือใน Hub
ไม่ต้องทำตัวแสดงผลแยกแต่ละชั้น ไม่ต้องเพิ่มรายการใน JavaScript
การเปิดไฟล์ด้วย file:// หรือเปิด HTML เดี่ยวโดยไม่มี Hub ไม่ได้ประกอบหน้าต่างกลางให้

A. ในไฟล์เมนูชั้น 2 หรือชั้น 3: เพิ่มรายการ <a> ภายใน <nav data-learning-menu>

<a data-tool-kind="html" data-content-id="chemistry-chapter-10-overview"
  href="acid-base/chapter-overview.html"
  data-th="ผลการเรียนรู้และสรุปบท" data-en="Learning outcomes and summary">
  ผลการเรียนรู้และสรุปบท
</a>

href ต้องนับจากไฟล์เมนูที่เขียน เช่นถ้าไฟล์เมนูอยู่ในแฟ้ม acid-base แล้ว ให้ใช้ chapter-overview.html
ปิดจากชั้น 2 จะกลับชั้น 2 ปิดจากชั้น 3 จะกลับชั้น 3

B. ใน HTML หน้าเว็บหรือหน้าอ่านที่แสดงอยู่แล้ว: เพิ่มลิงก์ปุ่มแบบนี้

<a data-hub-html data-content-id="chemistry-chapter-10-overview"
  href="../content/chemistry/acid-base/chapter-overview.html"
  data-th="ผลการเรียนรู้และสรุปบท" data-en="Learning outcomes and summary">
  ผลการเรียนรู้และสรุปบท
</a>

ตัวอย่าง href ข้างบนใช้จาก public/pages/chemistry.html
หากวางในหน้าสรุปที่อยู่โฟลเดอร์เดียวกับปลายทาง ให้แก้ href เป็นชื่อไฟล์ตรง ๆ
ลิงก์ต้องอยู่ใน HTML ที่แสดงจริง ไม่ใช่ใน <template> ที่ซ่อนไว้
หน้า subject เดิมสร้างเนื้อหาใน <main data-subject-page> ใหม่ จึงอย่าใส่ปุ่มเองภายใน main นี้
ถ้าจะเพิ่มปุ่มตรงใน public/pages/chemistry.html ให้วางนอก main และนอก template เช่นก่อนชุด script ท้าย body
ลิงก์บนหน้าเว็บธรรมดาปรับ CSS เองได้ ส่วนลิงก์ในไฟล์เมนูใช้หน้าตาการ์ดกลาง
สำหรับปุ่ม <button> ใช้ data-html-src แทน href ได้ใน HTML ที่ไม่ใช่ไฟล์เมนู
ต้องคง data-content-id เป็นรหัสอังกฤษตัวเล็กคั่นด้วย - ใช้รหัสเดิมเมื่อเปิดเอกสารเดิมหลายที่
ใช้รหัสใหม่สำหรับเอกสารคนละไฟล์ ระบบไม่ยอมให้รหัสเดียวกันเปิดสลับคนละไฟล์

C. ปุ่มท้ายชั้น 2 แบบเฉพาะสำหรับผลการเรียนรู้และสรุปทั้งบท: ใช้วิธี 2 ขั้นตอนด้านล่าง
รหัสปุ่มนี้สร้างอัตโนมัติเป็น <วิชา>-chapter-<เลขบท>-overview
เช่น chemistry-chapter-10-overview จึงใช้รหัสนี้ในลิงก์ A/B เพื่อเปิดหน้าต่างเดิมร่วมกันได้

ทำเองเพียง 2 อย่าง
-------------------
1. คัดลอกไฟล์:
   public/content/templates/chapter-overview-template.html
   ไปเป็น:
   public/content/chemistry/acid-base/chapter-overview.html

   แก้ชื่อบท ผลการเรียนรู้ และสาระสำคัญตามต้องการ
   ต้องคง data-learning-html บนแท็ก <html> ไว้:
   <html lang="th" data-learning-html>
   ใช้ HTML, CSS, รูปภาพ, ตาราง, sub/sup ได้ ไม่ต้องเขียน JavaScript
   หน้านี้เป็นเอกสารอ่านอย่างเดียว ระบบปิดสคริปต์ ฟอร์ม และสิทธิ์เข้าบัญชี
   ไม่ใช่ Simulation หรือ Quiz และไม่ต้องมีโจทย์หรือรหัส activity

2. ใน public/content/chemistry/acid-base.html เพิ่มที่แท็กเปิด <nav> เดิม:
   data-chapter-overview-src="acid-base/chapter-overview.html"

   ตัวอย่างแท็กเปิด (คงรายการเรื่องย่อยเดิมไว้ด้านใน):
   <nav data-learning-menu data-menu-kind="topics"
     data-subject-id="chemistry" data-chapter-id="10"
     data-title-th="บทที่ 10 กรด–เบส" data-title-en="Chapter 10 · Acids and Bases"
     data-chapter-overview-src="acid-base/chapter-overview.html">

   ลิงก์นับจากตำแหน่งไฟล์เมนูบท ไม่ใช่จากหน้าเว็บหลัก
   ไม่ต้องเพิ่ม <a> สรุปเป็นเรื่องย่อย และไม่ต้องสร้างเมนูชั้น 3 ให้สรุปบท
   ปุ่มจะอยู่ใต้เรื่องย่อย กดเปิดในหน้าต่างกลาง ปิดแล้วกลับชั้น 2

ถ้ายังไม่ได้เชื่อมบทให้เข้าชั้น 2
--------------------------------
ใน public/pages/chemistry.html ให้แท็กเปิดบท 10 เป็น:
<article data-chapter="10" data-chapter-src="../content/chemistry/acid-base.html">
คงชื่อและคำอธิบายบทเดิมไว้ ต้องมีไฟล์ acid-base.html จริงก่อนใส่ลิงก์

ถ้ายังไม่พร้อมเขียนสรุป
-------------------------
- ไม่ใส่ data-chapter-overview-src: ไม่มีปุ่มท้ายบท ระบบเดิมไม่เปลี่ยน
- ใส่ data-chapter-overview-src="": แสดงปุ่มกำลังเตรียมเนื้อหา แต่ยังกดไม่ได้
- ใส่ลิงก์แล้ว: ต้องมีไฟล์จริงและมี <html data-learning-html> ไม่เช่นนั้นตัวตรวจจะเตือน

บทอื่นและวิชาอื่นทำแบบเดียวกัน เปลี่ยนชื่อโฟลเดอร์/ลิงก์ตามบท
ไม่ต้องแก้ JavaScript ซ้ำและไม่ต้องลงทะเบียนใน workspace.js
ชื่อปุ่มและหน้าต่างรองรับไทย/อังกฤษ เนื้อหาใน HTML แสดงตามที่ครูเขียน ไม่แปลให้อัตโนมัติ
ลิงก์ data-hub-html เปิด HTML อีกหน้าในหน้าต่างกลางได้ โดยหน้าเดิมยังอยู่
ไม่รองรับสคริปต์ ฟอร์ม หรือหน้าต่างเบราว์เซอร์ใหม่จากเอกสารอ่านอย่างเดียว

สมการคณิตศาสตร์ ฟิสิกส์ และเคมี (ระบบกลาง)
-----------------------------------------
แม่แบบมีสูตรตัวอย่างแล้ว และมี Prompt ที่ public/content/templates/chapter-overview-ai-prompt.txt
เมื่อเปิดผ่าน Hub ระบบจะโหลด MathJax + mhchem ที่เก็บไว้กับเว็บเฉพาะเมื่อพบสูตร
ไม่ต้องใส่ script หรือ onclick ไม่ต้องแก้ตัวตรวจเนื้อหา และไม่ต้องลงทะเบียนแต่ละบท
Quiz Player เดิมไม่เปลี่ยน ระบบอ่าน HTML นี้ยังไม่เพิ่มพิมพ์/PDF หรือแป้นพิมพ์สมการ

สูตรในย่อหน้า: <p>ค่าคงที่ \(K_a\) และไอออน \(\ce{H3O+}\)</p>
สูตรแยกบรรทัด: \[K_a=\frac{x^2}{C-x}\]
รากและเศษส่วน: \[x=\frac{-K_a+\sqrt{K_a^2+4K_a C}}{2}\]
เคมี: \[\ce{HA(aq) + H2O(l) <=> H3O+(aq) + A-(aq)}\]
ฟิสิกส์: \[\vec{F}=m\vec{a},\quad g=9.81\,\mathrm{m\,s^{-2}}\]

- รองรับ \(...\), \[...\] และ $$...$$ แต่ไม่ใช้ $...$ (กันสับสนกับสัญลักษณ์เงิน)
- สูตรต้องอยู่ในข้อความเดียว ห้ามแทรก sub/sup หรือแท็กอื่นภายในตัวคั่นสมการ
- ใน HTML เขียน < เป็น &lt; และ > เป็น &gt; ได้ ระบบอ่านเป็นเครื่องหมายเดิม
- ใส่สูตรในเซลล์ตารางได้ แต่ตารางกว้างควรครอบด้วย <div style="overflow-x:auto">
- สมการยาวเลื่อนแนวนอนภายในกรอบสูตรได้ โดยไม่บีบตัวอักษรจนเล็กอ่านไม่ออก
- ใส่ตัวอย่างโค้ดใน pre/code หรือใช้ data-no-math เพื่อไม่ให้ระบบจัดรูป
- ห้ามใช้ require, href, style, class หรือการกำหนด macro เองใน LaTeX
- เปิดผ่าน Hub ด้วย localhost/GitHub Pages จึงเห็นสมการ เปิดไฟล์เดี่ยว file:// ยังเห็น LaTeX ต้นฉบับ
- ข้อความเดิมและ sub/sup ยังใช้ได้ แต่ระบบไม่ได้แปลงข้อความเดิมให้เป็น LaTeX อัตโนมัติ
- สูตรผิดจะแสดงต้นฉบับและแจ้งเตือน ไม่ทำให้เนื้อหาส่วนอื่นหาย หากโหลดตัวแสดงสูตรไม่สำเร็จให้โหลดหน้า Hub ใหม่
- ไฟล์บทกรด–เบสเป็นงานของครู รอบนี้ไม่ได้แก้สูตรในไฟล์บทให้
