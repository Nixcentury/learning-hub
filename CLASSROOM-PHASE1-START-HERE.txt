คู่มือเริ่มใช้ Classroom เฟส 1 — ห้องและสมาชิก
==================================================

รอบนี้ทำอะไรได้
- ครูที่ได้รับอนุมัติสร้างห้อง ตั้งชื่อ และได้รหัส 8 ตัว
- นักเรียน / บัญชีทั่วไปที่เข้าสู่ระบบเข้าห้องด้วยรหัส
- ครูเจ้าของห้องเห็นสมาชิก นักเรียนเห็นเฉพาะห้องของตน ไม่เห็นรายชื่อเพื่อน
- เปิดเว็บใหม่หรือเปลี่ยนแท็บแล้วกลับมา ห้องยังอยู่เมื่อใช้บัญชีเดิม
- เข้าด้วยรหัสเดิมซ้ำไม่สร้างสมาชิกซ้ำ

ยังไม่อยู่ในเฟสนี้
- มอบหมายงาน เลือก Quiz เก็บ/รวมคะแนน หรือ Google Classroom
- ลบ/เปลี่ยนชื่อห้อง ถอนสมาชิก เปลี่ยนรหัส หรืออนุมัติผู้ขอเข้าห้อง
- ไม่ย้ายหรือแก้ข้อมูลคะแนนและ LMS เดิม

สถานะการส่งมอบ
โค้ดและการทดสอบบนเครื่องพร้อมแล้ว
ยังไม่ได้เผยแพร่ Rules นี้ลง Firebase จริง และยังไม่ได้ push GitHub ในรอบนี้
การทดสอบอัตโนมัติใช้บัญชีและฐานข้อมูลจำลอง ไม่ใช้ข้อมูลนักเรียนจริง

1. เปิดใช้ Rules เฟส 1 ก่อนทดสอบบัญชีจริง
--------------------------------------------------
บัญชีครูเดิม sattawat.b@sbs.ac.th ใช้ต่อได้ ไม่ต้องสร้างแอดมินเพิ่ม
ไม่ต้องสร้างห้องหรือสมาชิกในแท็บ Data ด้วยตนเอง ระบบจะสร้างเมื่อกดใช้งาน

ไฟล์ที่เตรียมไว้ในโฟลเดอร์ firebase:
  classroom-phase1.rules.json
    เฉพาะกิ่ง classroomV1 สำหรับนำไปเพิ่มภายใน rules ของปัจจุบัน
    ห้ามใช้ไฟล์ส่วนนี้แทน Rules ทั้งชุด เพราะจะตัดกิ่งเก่าออก

  classroom-phase1.merged-draft.json
    ร่างรวมกับ Rules เฟส 0 ที่บันทึกจากแชทไว้
    เก็บ lmsSessions / lmsPresence / lmsDirectMessages / lmsChatNotices /
    quizPresence / quizProgress / learningHub เดิมทุกกิ่ง และเพิ่ม classroomV1
    นี่ไม่ใช่สำเนา Rules สดจาก Firebase Console

ก่อนกด Publish:
  1) สำรอง Rules ปัจจุบันจาก Firebase Console ไว้ก่อน
  2) เทียบ Rules ปัจจุบันกับร่าง หากมีการแก้กิ่งอื่นหลังเฟส 0
     ให้เพิ่มเฉพาะ classroomV1 เข้า Rules ปัจจุบัน ห้ามทับกิ่งอื่น
  3) ห้ามตั้ง .read หรือ .write ที่รากเป็น true
  4) Publish หลังตรวจเทียบเสร็จ จึงเริ่มทดสอบ

หากยังไม่ได้เพิ่ม Rules หน้าห้องจะแจ้งว่าถูกปฏิเสธสิทธิ์
จะไม่แสดงข้อความว่าเซฟสำเร็จ หรือทำเหมือนว่าไม่มีห้อง

2. ทดสอบสั้น ๆ ด้วยครูหนึ่งบัญชีและนักเรียนอีกหนึ่งบัญชี
--------------------------------------------------
ครู: เปิด Learning Hub → แท็บห้องเรียน → เข้าสู่ระบบบัญชีครู
     ใส่ชื่อ เช่น ห้องทดลอง ม.5/1 → สร้างห้องและรับรหัส
     รอข้อความยืนยันสำเร็จ → คัดลอกรหัสส่งให้นักเรียน

นักเรียน: ใช้อีกเบราว์เซอร์/หน้าต่างส่วนตัวและ Google อีกบัญชี
          เปิด Learning Hub → ห้องเรียน → ใส่รหัส → เข้าร่วมห้อง
          ต้องเห็นชื่อห้อง แต่ไม่เห็นรายชื่อเพื่อนหรือปุ่มสร้างห้อง

ครู: ภายในห้องต้องเห็นชื่อนักเรียนที่เข้าร่วม
     ตรวจชื่อ/บัญชีกับเด็กด้วย ชื่อแสดงผลมาจากบัญชี ไม่ใช่การยืนยันตัวตนทางราชการ

ทดสอบต่อ:
  - นักเรียนรีเฟรช → เปิดห้องเดิมได้
  - ไปแท็บวิชาอื่น → กลับห้องเรียน → ห้องเดิมยังอยู่
  - ปิดแล้วเปิดเว็บใหม่ บัญชีเดิม → ห้องเดิมยังอยู่
  - กลับรายการห้อง แล้วใส่รหัสเดิมอีกครั้ง → จำนวนสมาชิกไม่เพิ่มซ้ำ
  - ลองรหัสผิด → แจ้งไม่พบรหัส ไม่เพิ่มห้อง
  - สลับเป็นบัญชีนักเรียนอีกคน → ไม่เห็นห้อง/รายชื่อจากบัญชีก่อนหน้า

ใช้รหัสเฉพาะกับผู้ที่ต้องการให้เข้าห้อง ผู้ที่ล็อกอินและมีรหัสสามารถเข้าร่วมได้
ยังไม่มีการคัดกรองผู้ขอเข้า/ลบสมาชิก/เปลี่ยนรหัสในเฟส 1
จึงเริ่มด้วยห้องทดลองก่อนนำใช้กับห้องจริงจำนวนมาก

ถ้าเน็ตหลุดตอนกดสร้าง/เข้าร่วม ให้รอการยืนยัน
อย่ากดสร้างซ้ำหรือปิดหน้าขณะกำลังบันทึก
หากจำเป็นต้องเปิดใหม่ ให้ตรวจรายการห้องก่อนสร้างอีกครั้ง
ระบบนี้บันทึกห้องบน Firebase ไม่ได้พึ่งไฟล์ JSON สำรองสมุด

3. เมื่อนำขึ้น GitHub Pages
--------------------------------------------------
ใช้กระบวนการ build/publish เดิมของ Learning Hub
เปิดหน้าเว็บไซต์หลักตามด้วย #classroom ไม่เปิด pages/classroom.html เดี่ยว ๆ
หน้า Classroom ต้องรับบัญชีจาก Hub จึงจะทำงาน
Firebase จริงต้องติดตั้ง Rules เฟส 1 ด้วย มิฉะนั้นเว็บที่เผยแพร่จะถูกปฏิเสธสิทธิ์

4. สำหรับผู้พัฒนาที่จะต่อเฟสถัดไป
--------------------------------------------------
ดู firebase/CLASSROOM-PHASE1.md สำหรับโครงข้อมูลและวิธีทดสอบ
ใช้ roomId เป็นรหัสถาวรสำหรับการมอบหมายงานในอนาคต ไม่ใช้รหัสเข้าห้องเป็น ID งาน
เฟสถัดไปค่อยเชื่อมรายวิชา → งาน → assignmentId → ผลของนักเรียน
ห้ามเปลี่ยนสิทธิ์ให้นักเรียนอ่านคะแนนหรือรายชื่อเพื่อนเพื่อแก้ปัญหาการเชื่อม
