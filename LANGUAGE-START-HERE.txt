ปุ่ม TH / EN กลางสำหรับ Quiz, Simulation และ HTML
=================================================
ปรับในเครื่องวันที่ 1 ตุลาคม 2026 ยังไม่ได้เผยแพร่บน GitHub Pages ในรอบนี้

วิธีใช้
-------
เปิดงานผ่าน Learning Hub แล้วกด TH หรือ EN บนหัวหน้าต่างงาน
ภาษาจะตรงกับปุ่มภาษาหลักของเว็บและทุกหน้าต่างที่เปิดอยู่
ปุ่มภาษาเดิมภายใน Quiz ยังใช้ได้ และแจ้งภาษากลับให้หัวหน้าต่างตรงกัน
ระบบไม่โหลด iframe ใหม่ ไม่เปลี่ยน content ID และไม่ล้างคำตอบเพื่อสลับภาษา
ไม่ใช่ระบบแปลอัตโนมัติ ผู้สร้างต้องเตรียมคำแปลเอง

1. หน้า HTML อ่านเนื้อหา / สรุป / ผลการเรียนรู้
--------------------------------------------
ใช้ <html lang="th" data-learning-html> ตามเดิม ห้ามเพิ่ม script เพื่อทำปุ่มภาษา
เนื้อหายาวให้แยกเป็นสองบล็อกที่มี parent เดียวกัน:

<main>
  <section data-content-lang="th" lang="th">
    <h1>สรุปบทเรียน</h1>
    <p>สมการ \(K_a = \frac{x^2}{C-x}\)</p>
  </section>
  <section data-content-lang="en" lang="en" hidden>
    <h1>Chapter summary</h1>
    <p>Equation \(K_a = \frac{x^2}{C-x}\)</p>
  </section>
</main>

ใส่ตาราง รูป สมการ และย่อหน้าต่าง ๆ ไว้ภายในบล็อกแต่ละภาษาได้
ถ้าบล็อกกลุ่มหนึ่งมีแค่ภาษาเดียว ระบบยังแสดงภาษานั้น ไม่ทำให้เนื้อหาหาย
เอกสารเก่าที่เขียนไทยและอังกฤษปนกันโดยไม่กำกับบล็อก จะยังแสดงเหมือนเดิม
ต้องใส่ data-content-lang ก่อน ระบบไม่เดาว่าข้อความไหนเป็นภาษาใด
พิมพ์/PDF จากปุ่มกลางใช้ภาษาที่กำลังแสดง ไม่รวมบล็อกคำแปลที่ซ่อนอยู่

ข้อความสั้น (ไม่มีปุ่ม รูป หรือโครงสร้าง HTML ซ้อนข้างใน) ใช้:
<span data-th="ความเข้มข้น" data-en="Concentration">ความเข้มข้น</span>
data-th / data-en เป็นข้อความล้วน ไม่ใช่โค้ด HTML
ถ้ามี HTML ซ้อน ให้ใช้บล็อกภาษา อย่ากำกับ data-th/data-en บน container ทั้งก้อน
ไม่เปลี่ยนรหัสของปุ่ม ช่องคำตอบ หรือวัตถุในซิมตามภาษา

2. Quiz
-------
ใช้แม่แบบเดิม public/content/templates/quiz-template.html
ข้อความสั้นใช้ data-th / data-en ในส่วนที่แม่แบบกำหนด
เนื้อหา Quiz แบบ rich HTML ใช้ data-quiz-language="th" / "en" ตามแม่แบบ
อย่าเปลี่ยนเป็น data-content-lang ใน Quiz เพราะ Quiz Engine มีรูปแบบของตัวเอง
Quiz ลากวางต้องใช้ช่องวางและรหัสตัวเลือกชุดเดียวกันทั้งสองภาษา ไม่คัดลอกช่องวางซ้ำ
ไม่ต้องเพิ่ม script หรือปุ่มภาษาในไฟล์โจทย์

3. Simulation
-------------
ข้อความบนหน้า HTML ของซิมใช้ data-th/data-en และ data-content-lang ได้แบบเดียวกับข้อ 1
สำหรับข้อความที่วาดด้วย JavaScript, กราฟ, Canvas หรือสร้างหลังการโต้ตอบ:
รับข้อความภาษาจาก Hub แล้ววาดเฉพาะข้อความใหม่ โดยรักษาค่าทดลองเดิม เช่น

window.addEventListener('message', event => {
  if (event.source !== parent || event.origin !== location.origin) return;
  if (event.data?.type !== 'learning-hub-context') return;
  const language = event.data.language === 'en' ? 'en' : 'th';
  // เปลี่ยนข้อความของซิม / วาด label กราฟใหม่ ตาม language
  // ห้าม reset ค่า pH สารทดลอง ภารกิจ คำตอบ เวลา หรือ state ของผู้เรียน
});

โค้ดตัวอย่างนี้ใช้ใน Simulation เท่านั้น ไม่ใส่ใน HTML อ่านเนื้อหาหรือไฟล์โจทย์ Quiz
ถ้าซิมใช้ HubContext.subscribe อยู่แล้ว ให้อ่าน context.language จากช่องทางเดิม
ไม่ต้องติดตั้งตัวรับทั้งสองแบบซ้ำกัน
ปุ่มกลางไม่ได้แปลข้อความใน Canvas ของซิมเก่าที่ไม่รองรับข้อมูลภาษาโดยอัตโนมัติ

ข้อความสั่ง AI แบบสั้น
--------------------
สร้างเนื้อหาสองภาษา TH/EN สำหรับ Learning Hub และใช้ปุ่มภาษากลางของระบบ
ไม่สร้างปุ่มภาษาใหม่ ไม่รีโหลดหน้า ไม่เริ่มกิจกรรมใหม่เมื่อเปลี่ยนภาษา
HTML อ่านเนื้อหาใช้ data-content-lang เป็นบล็อกคู่ภายใต้ parent เดียวกัน
Quiz ใช้โครงภาษาเดิมจาก quiz-template.html และคงรหัสคำถาม/ตัวเลือก/ช่องวาง
Simulation ต้องรับ learning-hub-context จาก parent ที่เป็น origin เดียวกัน
แล้วเปลี่ยนข้อความและ label กราฟตาม language โดยคง state การทดลองเดิม
ข้อความสองภาษาต้องมีความหมายเทียบเท่ากัน ห้ามแสดงสองภาษาซ้อนกันโดยไม่จำเป็น

การตรวจรอบนี้
------------
ทดสอบเบราว์เซอร์ในเครื่อง: ปุ่มหัวหน้าต่างและปุ่มใน Quiz ตรงกัน
คำตอบและข้อความวิธีทำไม่หายเมื่อสลับภาษา
ซิมได้รับ language และค่าช่องทดลองยังอยู่
HTML แสดงทีละภาษา, fallback เนื้อหาภาษาเดียว, MathJax เปลี่ยนตามข้อความ
ตัวอย่างพิมพ์ไม่มีบล็อกคำแปลที่ซ่อนอยู่
ยังต้องลอง Safari/iPad จริงหลังเผยแพร่
