สถานะและขอบเขต
----------------
งานย่อยนี้เชื่อมหน้า <html data-learning-html> เข้าตัวจัดหน้า A4 กลางแล้ว
ใช้ปุ่มพิมพ์/PDF เดิมบนหน้าต่าง HTML ได้จากทุกชั้นของ Hub
ไม่ต้องเพิ่ม script, onclick, window.print() หรือปุ่มในไฟล์เนื้อหา
งานลิงก์เฟส 1–2 คงเดิม ไม่เริ่มลิงก์เฟส 3 ในรอบนี้
ยังไม่เชื่อม Quiz/สมุดจด/Simulation เข้าตัวจัดหน้าใหม่ ปุ่มพิมพ์ Quiz เดิมยังทำงานแบบเดิม
ยังไม่ commit/push หรือเปลี่ยน GitHub Pages/Firebase อัตโนมัติ

ทดลองใช้งาน
------------
1. เปิดเว็บในเครื่อง > เคมี > บทที่ 10 กรด–เบส > ผลการเรียนรู้และสรุปบท
2. กดพิมพ์/PDF บนแถบหน้าต่าง ระบบรอ MathJax รูป และฟอนต์ก่อนแบ่งหน้า
3. ตัวอย่างแบ่งหน้าสำหรับ A4 เลขหน้าอยู่กลางและชื่อ Nix-century อยู่ขวา
4. หากต้องการแก้ชื่อ เปิด “ตั้งค่าหน้าพิมพ์และชื่อบนหัว–ท้าย” แล้วกดจัดหน้าใหม่
   แก้เฉพาะรอบพิมพ์ ไม่แก้ไฟล์ต้นฉบับ รหัสเนื้อหา หรือบันทึกนักเรียน
5. พิมพ์/บันทึก PDF: เลือก A4 แนวตั้ง ขนาด 100%/ขนาดจริง ระยะขอบไม่มี
   หากอุปกรณ์มีตัวเลือก ให้ปิดหัว–ท้ายอัตโนมัติ (URL/วันที่) หัว–ท้ายของระบบยังอยู่
   ตรวจจำนวนหน้าในหน้าต่างพิมพ์ของอุปกรณ์อีกครั้ง

Safari / iPad: หน้าว่างสลับหลังทุกหน้า
---------------------------------------
ไฟล์รายงานจากผู้ใช้มีเนื้อหา 7 หน้า แต่ Safari ส่งออก 14 หน้า มีหน้าว่างทุกหน้าคู่
แก้ที่ระบบกลาง ไม่แก้เนื้อหา: iPad/iPhone เลือก “เผื่อขอบอุปกรณ์” อัตโนมัติ
ครอบคลุม iPad ที่รายงานตัวเหมือน Mac; Mac ปกติ, Android และ Windows ยังใช้แบบเดิม
- กระดาษยัง A4 แต่จัดเนื้อหาในพื้นที่ 180 x 260 mm เพื่อเผื่อขอบ/ท้ายของอุปกรณ์
- จัดหน้าใหม่ด้วยขนาดตัวอักษรเดิม ไม่ย่อทั้งหน้า ไม่ซ่อนหรือตัดเนื้อหา
- ใช้กล่องพิมพ์แบบ block และขึ้นหน้าใหม่ก่อนแผ่นถัดไป ไม่บังคับขึ้นหน้าหลังแผ่นสุดท้าย
- เลือกพื้นที่พิมพ์เองได้ใน “ตั้งค่าหน้าพิมพ์และชื่อบนหัว–ท้าย” แล้วกด “จัดหน้าใหม่”
- จำนวนหน้าอาจเปลี่ยนตามเนื้อหา ให้เทียบจำนวนในตัวอย่างกับหน้าต่างพิมพ์ของอุปกรณ์
- Safari อาจยังเติม URL/วันที่ และอาจไม่มีปุ่มปิด: รอบนี้ไม่ได้ลบสิ่งที่เบราว์เซอร์เติม
- การทดสอบจำลองระยะขอบบน Chromium ไม่ใช่การยืนยันการพิมพ์บน Safari/iPad จริง
ต้องให้ผู้ใช้ทดสอบไฟล์ใหม่บน iPad หลังเผยแพร่ก่อนปิดงานนี้

หัว–ท้ายมาตรฐาน
----------------
หัวซ้าย: วิชา          หัวกลาง: ชื่อบท       หัวขวา: ชื่อเรื่อง
ท้ายซ้าย: ชื่องานย่อย   ท้ายกลาง: หน้า x / y   ท้ายขวา: Nix-century
ไม่มีชื่อ/ชั้น/เลขที่ ไม่มีเส้นสำหรับเขียน ไม่มีหัวเรื่องย่อยปลอมเมื่อเป็นสรุปทั้งบท
เอกสารอ่านไม่เพิ่มพื้นที่วิธีทำหรือพื้นที่จดโดยอัตโนมัติ

ชื่อเอกสารจากที่ไหน
--------------------
ใช้ชื่อจากสารบัญเส้นทางเดิมตาม subjectId/chapterId/topicId ที่เปิดงาน
ไม่มีข้อมูลให้เว้นว่าง ไม่เดาชื่อจากรหัสและไม่ใส่ชื่อบทซ้ำในช่องเรื่อง
ผู้เขียนอาจกำหนดชื่อเฉพาะไฟล์บน html ได้ (ไม่บังคับ):
<html lang="th" data-learning-html
  data-print-subject="เคมี"
  data-print-chapter="บทที่ 10 กรด–เบส"
  data-print-topic=""
  data-print-work="ผลการเรียนรู้และสรุปบท">
รองรับ data-print-subject-th / -en เช่นเดียวกับ chapter, topic, work
ค่าระบุเป็นข้อความธรรมดา ไม่ใช่ HTML; ค่าว่างหมายถึงตั้งใจเว้นว่าง
โหลดสารบัญไม่ได้ยังพิมพ์ได้ โดยเติมชื่อผ่านหน้าตัวอย่างเอง

ความครบถ้วนของเนื้อหา
----------------------
- ทำงานกับสำเนาเอกสารที่แสดงแล้ว ไม่แก้เนื้อหาหน้าอ่าน
- รูปสัมพัทธ์อ้างตำแหน่ง HTML ต้นทาง ไม่ใช่ตำแหน่งหน้า Hub
- รูป img (รวม .svg), inline SVG, SVG สมการ MathJax และตารางยังอยู่
- รอรูปที่อยู่ใน SVG และภาพพื้นหลังด้วย ถ้าโหลดไม่ได้ปิดปุ่มพิมพ์พร้อมแจ้งเตือน
- use ที่อ้าง SVG จากไฟล์ภายนอกยังไม่รองรับ: ใช้ SVG inline หรือ img src="...svg"
- ตารางยาวแบ่งระหว่างแถว ซ้ำ thead และรักษากลุ่ม rowspan ไว้ด้วยกัน
- รายการ ol รักษาเลขต่อเนื่อง; ย่อหน้ายาวที่ไม่มีรูป/สมการแทรกแบ่งต่อหน้าได้
- ถ้าบล็อก รูป สมการ หรือกลุ่มแถวสูงกว่าหนึ่งหน้า ให้ผู้เขียนแบ่ง/ปรับก่อน
  ระบบจะไม่ซ่อนเนื้อหาและไม่เปิดปุ่มพิมพ์เมื่อจัดไม่ได้
- จำกัด 150 หน้าต่อการเตรียมพิมพ์ ป้องกันเอกสารผิดรูปแบบทำงานไม่จบ
- รูปแบบหน้าซับซ้อนมาก เช่น grid/flex หลายคอลัมน์ หรือ CSS ตำแหน่งตายตัว
  ต้องมีตัวอย่างทดสอบเพิ่มเติม ไม่อ้างว่ารองรับ HTML ทุกชนิดโดยอัตโนมัติ
- คง sandbox ของหน้าอ่านและหน้าพิมพ์ ไม่ให้สคริปต์ในเนื้อหาทำงาน

งานย่อย 2 — Quiz ทั้งข้อกาและเติมคำ/ตัวเลข/สมการ และชุดลากวาง
- ตัวเชื่อม Quiz ส่งโจทย์/ตัวเลือกเข้าแกนกลาง
- ตัวเลือกเรียงแนวนอนและขึ้นบรรทัดเมื่อไม่พอ
- พื้นที่คำตอบ/วิธีทำว่าง ไม่มีเส้น; ประเมินจากขั้นตอนเฉลยและปรับรายข้อ
- ไม่พิมพ์เฉลยในใบโจทย์ และไม่พิมพ์แป้นพิมพ์/ปุ่มควบคุม
- แยก “พิมพ์ไว้ทำ” กับ “พิมพ์งานที่ทำแล้ว” ให้ชัด
- กรณีโจทย์ยาวเกินหน้าให้มีหน้าต่อพร้อมเลขข้อ ไม่ตัดโจทย์หาย
- ลากวางปรับเป็นตัวเลือกข้อความ/รูปและช่องตอบบนกระดาษ ไม่ผสมกับชุดข้อกาโดยบังคับ

งานย่อย 3 — Simulation / กิจกรรม / บันทึก
- กำหนดส่วนส่งภาพสถานะ ค่าตัวแปร ผลทดลอง และบันทึกเข้าระบบกลาง
- Canvas/กราฟเคลื่อนไหวต้องมีวิธีส่งภาพจากเครื่องมือนั้น ไม่พิมพ์หน้าว่าง
- ไม่อ้างว่า PDF เป็นไฟล์สำรองที่นำกลับมาแก้สมุดได้ งานนั้นแยกต่างหาก
