รหัสชื่ออ่านง่าย
--------------
ถ้าบทมี data-route-slug="acid-base" ระบบใช้ #chemistry/acid-base
แต่ #chemistry/10 ยังเข้าตำแหน่งเดียวกัน รหัสภายในของบทไม่เปลี่ยน
เฟสนี้ไม่ได้ใส่ชื่อเสริมแทนครูหรือแก้ HTML เนื้อหาของบทจริง
รายละเอียดการเพิ่มเนื้อหาและชื่อเก่าอยู่ใน SHARING-PHASE1-START-HERE.txt
เพิ่ม HTML และเชื่อมเมนูเดิมตามปกติ ไม่ต้องลงทะเบียนลิงก์แยกอีกชุด
ทดสอบด้วย pnpm dev หรือเว็บที่ Build แล้ว ไม่ใช่เปิด index.html แบบ file://

กรณีเนื้อหายังไม่พร้อมหรือโหลดไม่สำเร็จ
--------------------------------------
เรื่องย่อยไม่มี href: ลิงก์ตรงแสดงชื่อเรื่องกับข้อความกำลังเตรียมเนื้อหา
การ์ดเรื่องย่อยที่ยังไม่พร้อมในเมนูเดิมยังไม่เปิดให้คลิก ไม่มีเครื่องมือปลอม
บทใหม่ที่ยังไม่มีทั้งเมนู HTML และเครื่องมือรุ่นเก่าแสดงพื้นที่เตรียมเนื้อหา
ไม่พบรหัสในลิงก์: แจ้งเหตุและกลับไปหน้าบทหรือวิชาที่ใกล้ที่สุด
โหลดสารบัญไม่ได้: เก็บลิงก์ที่ขอไว้ ยังเปิดเมนูด้วยมือได้ และมีปุ่มลองอีกครั้ง
โหลดเมนูไม่ได้: ไม่เปลี่ยนไปเป็นงานอื่น มีแจ้งเหตุและลองอีกครั้ง

ขอบเขตที่ยังไม่ทำ
----------------
ลิงก์เปิดหน้าต่าง Quiz / Simulation / HTML โดยตรง เป็นเฟส 3
หากนำลิงก์ระดับงานจากคู่มือเฟส 1 มาเปิดตอนนี้ จะเปิดเมนูแม่พร้อมคำชี้แจง
การเปิดงานด้วยปุ่มเดิมยังใช้ได้ และ URL คงอยู่ที่เมนูของงาน
การเปลี่ยนบทหรือวิชาไม่ปิดหน้าต่างงานที่เปิดอยู่ ไม่เปลี่ยนระบบบันทึกเดิม
ไม่มี UID คำตอบ โน้ต คะแนน หรือสิทธิ์บัญชีในประวัติการนำทาง
ไม่มีลิงก์เข้าห้องเรียนส่วนตัวหรือคะแนนนักเรียน และไม่แก้ Firebase Rules

ตรวจสอบก่อนเผยแพร่
------------------
pnpm test:unit
pnpm test:sharing:browser
pnpm build

Browser test ใช้เมนูตัวอย่างเสมือนเพื่อทดสอบหัวข้อที่มี Quiz และ alias
ไม่ได้เพิ่มเมนูตัวอย่างนั้นลงเนื้อหาจริง ไม่ติดต่อ Firebase หรือ AI จริง
หลัง Build ตั้ง QA_BUILT=1 แล้วรัน test:sharing:browser เพื่อทดสอบชุดเผยแพร่
ยังต้องลอง Safari/iPad จริงหลังเผยแพร่ ใช้บัญชีและโหมดเดิม อย่าล้างข้อมูลเว็บไซต์
