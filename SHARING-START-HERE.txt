ใช้อย่างไร
----------
1. เปิด Learning Hub ผ่านเว็บหรือเซิร์ฟเวอร์ในเครื่อง ไม่ใช่ file://
2. เลือกวิชา > บท > เรื่องย่อย > เปิดงานตามปกติ
3. URL จะตามตำแหน่งที่เลือก รวมถึงหน้าต่างงานที่กำลังใช้อยู่
4. กด “แชร์ลิงก์” บนหัวเว็บ หรือ “แชร์” บนหัวหน้าต่างงาน
5. กด “คัดลอกลิงก์” แล้วส่งให้ผู้เรียน
   ถ้าเบราว์เซอร์ไม่อนุญาตให้คัดลอก จะเลือกข้อความให้คัดลอกเองได้
6. ผู้รับเข้าสู่ระบบหรือเลือกผู้เยี่ยมชมตามปกติ แล้วระบบเปิดงานที่ขอไว้

แชร์อะไรได้
-----------
- หน้าวิชา บท เรื่องย่อย และหน้าหลักที่มีในเมนู
- Quiz ข้อกา เติมคำตอบ และลากวางที่เชื่อมเข้าระบบแล้ว
- Simulation และ HTML อ่านเนื้อหา/สรุป/ผลการเรียนรู้ที่เชื่อมเข้าระบบ
- ปุ่ม data-hub-html ที่เชื่อมจากหน้าหลัก วิชา หรือเนื้อหาที่ลงทะเบียนแล้ว
- เครื่องมือรุ่นเดิมที่ปรากฏในเมนู (คงรหัสบันทึกเดิม)

รูปแบบทั่วไปของงานใหม่
#วิชา/บท/เรื่องย่อย/content-id
หรือ #content/content-id
ใช้ปุ่มแชร์เพื่อรับลิงก์ที่ถูกต้อง ไม่ต้องพิมพ์หรือเดารหัสเอง

เพิ่มเนื้อหาในอนาคต
-------------------
สร้าง HTML และเชื่อมเมนูตามกติกาเดิม สารบัญลิงก์สร้างให้อัตโนมัติตอน Build
ไม่ต้องแก้ไฟล์ JavaScript หรือลงทะเบียนลิงก์ซ้ำด้วยมือ
ไฟล์ที่วางเฉย ๆ โดยยังไม่เชื่อมเข้าระบบ จะยังไม่มีลิงก์จากปุ่มแชร์กลาง
ห้ามเปลี่ยน content-id / activity-id ของงานเดิมเพียงเพื่อเปลี่ยนชื่อ URL
ถ้าย้ายไฟล์ ให้แก้ href ในเมนู แต่คง ID เดิม งานบันทึกเดิมจึงยังผูกงานเดิม
เปลี่ยนชื่ออ่านง่ายได้ด้วย data-route-slug และเก็บชื่อเก่าใน data-route-aliases

Back / Forward / หลายหน้าต่าง
-----------------------------
กลับเมนูหรือเปลี่ยนวิชา: ย่อหน้าต่างงานไว้ในแถบล่าง ไม่ปิดทิ้ง
กด Forward หรือเรียกงานกลับ: ใช้หน้าต่างเดิม ถ้ายังเปิดอยู่
กดปิด: ใช้ขั้นตอนตรวจการเซฟของควิซเดิม ไม่ข้ามคำเตือนเรื่องบันทึก
ลิงก์เก็บตำแหน่งงานเดียว ไม่ได้เก็บชุดหน้าต่างทั้งหมดที่เปิดอยู่

ความเป็นส่วนตัวและข้อจำกัด
--------------------------
ลิงก์ไม่มี UID คำตอบ โน้ต คะแนน รหัสห้อง หรือข้อมูลเซสชัน
ผู้รับใช้บัญชีและงานบันทึกของตัวเอง ไม่ได้รับคำตอบของคนส่ง
ผู้เยี่ยมชมยังไม่บันทึก Cloud เช่นเดิม ลิงก์ไม่เพิ่มสิทธิ์ให้บัญชี
Classroom แชร์ได้แค่หน้าห้องเรียนหลัก ไม่ใช่ห้องส่วนตัวหรือตารางคะแนน
ลิงก์ในเครื่อง (127.0.0.1) ส่งให้คนอื่นใช้ไม่ได้ ต้องแชร์จากเว็บจริงหลัง Deploy
Simulation จะกลับมาหลังรีเฟรชได้แค่ไหนขึ้นกับระบบบันทึกของ Simulation นั้น
ระบบลิงก์นี้ไม่ได้เพิ่มการเซฟให้ทุก Simulation โดยอัตโนมัติ

เช็กลิสต์ลองจริง
---------------
เปิดควิซ > ตอบ/จด > แชร์ > เปิดแท็บใหม่ > ล็อกอินบัญชีเดิม
ลองแชร์ให้บัญชีเด็กอีกบัญชี: เห็นโจทย์เดียวกันแต่ไม่เห็นคำตอบคนส่ง
ลอง Back/Forward และย่อ/เรียกกลับ โดยตรวจคำตอบและโน้ตยังอยู่
ลองหน้าอ่านสรุปและซิม แล้วคัดลอกลิงก์บน iPad ทั้งแนวตั้งและแนวนอน
