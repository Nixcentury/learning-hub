เผยแพร่
--------
Commit และ Push ไป main ของ Nixcentury/learning-hub เท่านั้น
ตั้ง Settings > Pages > Source เป็น GitHub Actions ไว้แล้ว ไม่ต้องตั้งซ้ำ
เปิด Actions แล้วตรวจงาน Learning Hub Pages ให้ผ่านทั้ง build และ deploy
ตรวจ deployment.json บนเว็บว่าค่า commit ตรงกับเวอร์ชันที่ส่งขึ้น
หาก build ไม่ผ่าน เว็บจะยังเป็นรุ่นก่อนหน้า ให้ดูข้อความผิดพลาดใน Actions
หาก build/deploy ผ่านแต่เห็นเนื้อหาเก่า ให้ตรวจลิงก์ปลายทางและลองหน้าต่างส่วนตัวก่อน
อย่าล้างข้อมูลเว็บไซต์ทันที เพราะอาจลบสมุดที่เก็บในเครื่อง

ไม่ต้องแก้ dist เอง — สร้างใหม่ทุกครั้งและไม่เก็บโฟลเดอร์นี้ลง Git
ทดสอบก่อนแจก: เปิด Hub > วิชา > บท > เรื่อง > ชุดงาน ตรวจชื่อ โจทย์ และเฉลย
ลิงก์เล่น Quiz ไม่ใช่ไฟล์เนื้อหาโดยตรง เช่น:
https://nixcentury.github.io/learning-hub/pages/tools/quiz-player.html?content=../../content/samples/numeric-input-demo.html&lang=th
ลิงก์ Player เดี่ยวใช้บริบท Guest ในเครื่อง ถ้าต้องการคำตอบผูกบัญชี/Cloud ให้เปิดชุดผ่าน Hub
งาน Guest กับงานในบัญชีแยกกัน ไม่ควรใช้สองทางสลับกันเพื่อทดสอบว่างานหายหรือไม่
ห้ามใส่รหัสลับ บัญชีนักเรียน หรือข้อมูลคะแนนจริงไว้ใน public หรือ Git
Firebase และ AI Worker ยังเป็นระบบเดิม การย้ายนี้ไม่เผยแพร่ Rules หรือย้ายข้อมูลในฐานข้อมูล

สำเนา Hub ใน Physic-subject มีไว้ย้อนกลับ อย่าแก้เนื้อหา Hub สองที่พร้อมกัน
ลิงก์เครื่องมือเก่ามีสำเนาฉบับก่อนย้ายรองรับ แต่จะไม่ได้ฟีเจอร์หรือเนื้อหาใหม่ตามเว็บนี้
อย่าลบ .github/hub-compat ใน Physic-subject เพราะใช้รองรับลิงก์เก่า

ทดสอบบน iPad ก่อนใช้กับนักเรียน
-------------------------------
1. ถ้ามีงานเดิม ให้สำรอง JSON ก่อนทดสอบ อย่าล้างข้อมูลเว็บไซต์
2. เปิด Hub ใหม่ใน Safari ปกติ ใช้บัญชีเดิมหรือ Guest แบบเดิมตลอดรอบทดสอบ
3. เปิดแท็บ Test > บท 2 แล้วเปิดชุดเติมคำตอบ เขียนโน้ตสั้น ๆ ในข้อเดิม
4. รีเฟรช ปิดหน้าต่างงานแล้วเปิดชุดเดิม และเปิด Hub ในแท็บใหม่แล้วเลือกชุดเดิมอีกครั้ง
   ตรวจว่าคำตอบและลายมือของข้อเดิมกลับมา โดยไม่สลับบัญชีหรือโหมด Guest
   ถ้าทดสอบ Player เดี่ยว ให้ใช้ลิงก์ Player เดี่ยวแบบ Guest ตั้งแต่เริ่มจนจบ
5. ถ้ามีปัญหา เก็บลิงก์ ชื่อชุด หมายเลขข้อ และข้อความสถานะบันทึกไว้แจ้ง
6. การทดสอบในเครื่องนี้ไม่ยืนยัน Apple Pencil, AI, การบันทึก Cloud หรือสิทธิ์ Classroom จริง
   ส่วนเหล่านี้ยังต้องตรวจแยกด้วยบัญชีและอุปกรณ์จริง ไม่ต้องแก้ Firebase ในรอบย้ายเว็บ

ผลตรวจและข้อจำกัดบันทึกไว้ใน MIGRATION.md
