# ลิงก์ของห้อง / Classroom links

กล่องซ้ายของ Classroom ใช้ Firebase Realtime Database เดิม ไม่ต้องตั้ง Sheet, Apps Script, Cloud Functions หรือเปลี่ยนแพ็กเกจสำหรับติดตั้งฟีเจอร์นี้ ไฟล์จริงอยู่ในเว็บไซต์ต้นทาง เก็บเฉพาะชื่อ URL ผู้เพิ่ม วันที่ และเลข revision ใน `classroomLinksV1/items/{roomId}/{linkId}`

## ติดตั้ง

1. ใช้ Rules ชุดเต็ม `firebase/classroom-links.merged-draft.json` แทนฉบับ `firebase-rules-with-prerequisites-20261031.json` ที่ส่งให้วันที่ 31 ต.ค. 2026 ตรวจว่าไม่ได้แก้ Rules บน Console เพิ่มหลังฉบับนั้น
2. เปิด Firebase Console ของโปรเจกต์เดิม → Realtime Database → Rules วาง JSON ทั้งไฟล์แล้ว Publish ด้วยบัญชีเจ้าของโปรเจกต์ โค้ดนี้ไม่มีขั้นตอน deploy Rules อัตโนมัติ
3. Merge PR และรอ GitHub Pages อัปเดต จากนั้นโหลด Hub ใหม่ เปิด Classroom → ห้อง → ลิงก์ของห้อง → + ลิงก์อื่น
4. ใส่ชื่อและ URL เต็ม (`https://` หรือ `http://`) แล้วรอข้อความยืนยัน สมาชิกห้องอื่นจะเห็นรายการใหม่อัตโนมัติเมื่อเปิดห้องเดียวกัน

Rules ชุดเต็มเพิ่มเฉพาะ `classroomLinksV1` ส่วนอื่นคงเดิม รวมคะแนน คำตอบ เงื่อนไขปลดงาน ประวัติส่งซ้ำ และคาบเรียน หากมีการแก้ Rules หลังฉบับอ้างอิง ให้ export ฉบับปัจจุบันและใช้ตัวรวม Rules ด้านล่างก่อน ไม่ใช้ไฟล์ชุดเต็มเก่าทับการแก้ใหม่

```sh
node scripts/build-classroom-links-rules.mjs /absolute/path/current-rules.json /absolute/path/rules-with-links.json
```

ตัวรวมปฏิเสธ root ที่ไม่ได้ปิดและ namespace ลิงก์ที่มีอยู่แล้ว จะไม่แทนที่กติกาที่ไม่รู้จัก ไฟล์ `firebase/classroom-links.rules.json` เป็นเฉพาะส่วนลิงก์สำหรับตรวจโค้ด ไม่ใช่ไฟล์ชุดเต็มสำหรับวางแทนทั้ง Console

## สิทธิ์และการใช้งาน

| บัญชี | อ่าน/เพิ่ม | แก้ไข/ลบ |
| --- | --- | --- |
| สมาชิกในห้อง | ได้ | รายการของตัวเอง |
| ครูที่ยังได้รับอนุมัติและเป็นเจ้าของห้อง | ได้ | ทุกรายการในห้อง |
| บุคคลนอกห้อง/ครูห้องอื่น/ผู้ไม่ได้ล็อกอิน | ไม่ได้ | ไม่ได้ |

ครูที่เข้าร่วมในฐานะสมาชิกห้องของครูคนอื่นมีสิทธิ์สมาชิกเท่านั้น Rules ตรวจสมาชิกและเจ้าของจริง ไม่ใช้ role ที่หน้าเว็บส่งมา ผู้เพิ่มและวันที่สร้างเปลี่ยนไม่ได้แม้ครูแก้ข้อความ วันที่แสดงตามเวลาไทย ลิงก์เปิดแท็บใหม่ด้วย `noopener noreferrer` และข้อความผู้ใช้ไม่ถูกแปลงเป็น HTML

โหลดและฟังเฉพาะลิงก์ของห้องที่เปิด หยุด listener เมื่อกลับรายการห้อง เปลี่ยนวิชา เปลี่ยนบัญชี หรือเสียสิทธิ์ ไม่ดาวน์โหลดลิงก์ครบทั้ง 7 ห้องล่วงหน้า สมาชิกทั้งหมดประมาณ 112 คนไม่ใช่จำนวน connection ที่ต้องเปิดพร้อมกัน ฟีเจอร์นี้ใช้ SDK/การเชื่อมต่อฐานข้อมูลเดิมของ Hub

เมื่อออฟไลน์จะไม่รับคำสั่งใหม่เพื่อเข้าคิวอย่างเงียบ ๆ รายการที่รอการยืนยันจะแสดงสถานะรอ ระบบแจ้งสำเร็จเมื่อ transaction ตอบกลับเท่านั้น การแก้พร้อมกันใช้ revision ป้องกันรอบเก่าทับรอบใหม่ หากชนกันให้ยกเลิกและเปิดแก้จากรายการล่าสุด คำสั่งที่ส่งถึงเซิร์ฟเวอร์ไปก่อนเปลี่ยนหน้าอาจเสร็จในห้องเดิม แต่ผลตอบกลับเก่าจะไม่เปิดข้อมูลในบัญชี/ห้องใหม่

## ตรวจสอบ

`pnpm test:unit` ครอบคลุมฟอร์ม สิทธิ์แสดงปุ่ม URL ที่ไม่ปลอดภัย บัญชี/ห้องเปลี่ยน และ transaction ชนกัน `pnpm test:monitor:rules` เพิ่มชุด Rules ลิงก์ด้วย Firebase emulator และยังรัน regression ของห้อง คาบเรียน การบ้าน และการส่งซ้ำเดิม

CI ทดสอบหน้า production ผ่าน browser ด้วยข้อมูลสังเคราะห์: นักเรียนเพิ่ม → ครูเห็นและแก้ → ผู้เพิ่มเดิมยังอยู่ → นักเรียนลบ พร้อม layout TH/EN บน desktop, tablet และมือถือ ไม่ใช้บัญชีหรือข้อมูลนักเรียนจริง
