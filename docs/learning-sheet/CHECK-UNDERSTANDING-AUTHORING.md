# ตรวจความเข้าใจ / Check Your Understanding — กติกาสำหรับ AI

ใช้เอกสารนี้เมื่อเพิ่มใบตรวจความเข้าใจใน Learning Hub งานแรกคือเคมี 2.4
คำสั่งล่าสุดของครูและแบบคำถามที่ CF มีผลเหนือค่าตัวอย่างในเอกสารนี้

## ขั้นตอนและภาษา

1. อ่านเนื้อหาเดิมและแหล่งอ้างอิงจริงก่อนออกแบบ ครอบคลุมเนื้อหา สสวท. และทักษะจากแนว A-Level ที่เกี่ยวข้อง โดยไม่อ้างคำถามที่เรียบเรียงใหม่ว่าเป็นข้อสอบจริง
2. เสนอคำถาม เฉลย รูปแบบและจำนวนหน้าก่อนผลิต เมื่อครู CF แล้วทำชุดที่อนุมัติให้ครบ ไม่ขอ CF ซ้ำสำหรับขั้นตอนย่อยตามแบบเดิม
3. ใช้มาตรฐานผู้เขียนหนังสือเรียนทั้งไทยและอังกฤษ: ถูกต้อง กระชับ เป็นทางการ และเหมาะกับนักเรียนมัธยม อังกฤษต้องเป็นธรรมชาติ ไม่แปลเรียงคำตามภาษาไทย
4. TH/EN ต้องมีเงื่อนไข ข้อมูล ตัวลวง ความหมาย และระดับความยากตรงกัน ใช้ศัพท์วิทยาศาสตร์สม่ำเสมอและตรวจเฉลยทั้งสองภาษา

## รูปแบบคำถาม

- เติมความรู้: เขียนคำตอบสั้น ๆ ไม่ใช้ Sentence Bank ของเหตุผลเป็นแหล่งลอกคำตอบความรู้
- เรียงลำดับ/เปรียบเทียบ/อ่านข้อมูล: ระบุทิศการเรียง หน่วย ชนิดอนุภาค และชุดข้อมูลให้ชัด ไม่บังคับอธิบายทุกข้อ
- เติมเหตุผล: นักเรียนเลือกแล้วเขียนข้อความเอง ยอมรับถ้อยคำสมมูลที่ถูกต้อง
- ถูก–ผิด: นักเรียนเขียนเพียง ✓ หรือ ✗ เท่านั้น ไม่ให้เขียนเหตุผลหรือแก้ประโยค เหตุผลและประโยคแก้ไขอยู่ในเฉลย
- ข้อคำนวณที่จำเป็นจริง: โจทย์จบแล้วขึ้นบรรทัดใหม่เป็น “(คำตอบ: ตัวเลขพร้อมหน่วย)” ให้เห็นในฉบับนักเรียนและฉบับพิมพ์ เพื่อให้ตรวจตัวเอง นักเรียนต้องคิดและแสดงวิธีทำเอง ไม่รวมวิธีทำหรือคำตอบคำนวณใน Sentence Bank
- ไม่ต้องสร้างข้อคำนวณเพียงให้มีครบประเภท เคมี 2.4 ชุดแรกไม่มีข้อคำนวณแสดงวิธีทำ

## Sentence Bank

- เพิ่มเต็ม 1 หน้าด้านหลังต่อภาษา มีทั้งประโยคใช้ได้จริง ประโยคผิดบริบท และตัวลวงความเข้าใจคลาดเคลื่อนที่ชัดเจน
- จำนวนประโยคต้องไม่น้อยกว่า 2 เท่าของจำนวนข้อเติมเหตุผลที่ใช้คลังนั้น: M ≥ 2N
- งานแรก N = 10 จึงมี M = 20 ประโยคต่อภาษา: คำตอบเป้าหมาย 10 และตัวลวง 10 ไม่เปิดเผยสัดส่วนในฉบับนักเรียน
- ห้ามใส่รหัส ตัวเลข หรือตัวอักษรกำกับประโยค นักเรียนต้องเขียนข้อความ ไม่ตอบเป็นรหัส
- สลับลำดับ ไม่เรียงตามข้อ จัดประโยคให้รูปแบบและความยาวใกล้เคียงกัน อ่านได้ชัด ไม่ใช้ตัวอักษรเล็กเป็นกับดัก
- ประโยคหนึ่งใช้ได้มากกว่าหนึ่งข้อเมื่ออธิบายได้จริง ห้ามปฏิเสธเหตุผลถูกต้องเพียงเพราะต่างจากเฉลยเป้าหมาย
- คำชี้แจงต้องบอกว่ามีประโยคที่ไม่ถูกต้องด้วย ป้องกันการจดจำทั้งหน้าเป็นข้อเท็จจริง
- เฉลยต้องอธิบายความเข้าใจคลาดเคลื่อนที่ใช้เป็นตัวลวง

## ไฟล์และระบบกลาง

- ใช้สัญญา Learning Sheet: data-learning-html และ data-learning-sheet="1" คู่ภาษาใช้ semantic slot key เดียวกัน
- เฉลยทุกช่องอยู่ใน data-sheet-answer ซึ่งเป็นลูกโดยตรงของ data-sheet-slot ไม่ใส่คำตอบใน label
- แยกพื้นที่ตอบของข้อย่อย เว้นพื้นที่ว่าง ไม่มีเส้นบรรทัดหรือจุดประ
- ใช้ระบบภาษา เปิด–ปิดเฉลย MathJax ไกด์ และการพิมพ์กลาง ห้ามเพิ่มสคริปต์หรือ toolbar ลงใน HTML เนื้อหา
- สร้าง guide JSON จากเนื้อหาจริง มีเป้าหมายและสรุป TH/EN ทุกช่วง ตรวจ target, revision และ SHA-256
- ใช้ bankKey จริงจากเมนู ไม่เดารหัสหรือเปลี่ยน ID ของงานเดิม เพิ่ม contentId และ tool-key ใหม่ที่ไม่ชนกัน
- ห้ามรายงาน QA จากการอ่านโค้ดเพียงอย่างเดียว ต้องแยกผลโครงสร้าง เปิดเว็บ พิมพ์ และอุปกรณ์จริง
