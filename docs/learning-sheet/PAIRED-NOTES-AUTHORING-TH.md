## 3. Classroom Note · กระดาษที่ครูใช้เขียนสอน

1. เปิดด้วยชื่อใบและช่องชื่อ/ห้อง จากนั้นลิงก์ไปแล็บและใบคู่กันบนจอ
2. เตรียมเฉพาะคำศัพท์ สมการ หรือแนวคิดที่ต้องใช้ทันที ต้นแบบใช้สะเทิน pH/pOH ไทเทรต จุดยุติ จุดสมมูล และคู่ฟอสเฟตตามลำดับกิจกรรม
3. ให้ดูรูปอุปกรณ์หรือกราฟก่อน แล้วเว้นตารางที่จดค่าจริงได้ ใส่หัวตาราง ชื่อสาร หน่วย และลำดับที่อ่านค่า ข้อมูลตัวอย่างที่วางไว้ให้ทดลองทำต้องกำกับว่าเป็นข้อมูลตัวอย่าง
4. ถาม Check-out หนึ่งประเด็นจากสิ่งที่มองเห็น ให้ชี้ค่าหรือคู่เปรียบเทียบก่อนอธิบาย เช่น “หลังเติมกรดเท่ากัน ใบใดเปลี่ยน pH มากกว่า ใช้ค่าคู่ใดเปรียบเทียบ” ใช้ค่าที่อ่านได้โดยตรงและรักษาโจทย์คำนวณหลายขั้นไว้ในตัวอย่างหรือ Exit
5. สอนด้วยตัวอย่างเรียงตามวิธีที่เด็กต้องเลือก ให้ชื่อแต่ละตัวอย่างบอกงานที่ทำ ต้นแบบใช้ตัวอย่าง 1–7 และช่วงต่อยอด เช่น เปลี่ยนจากอัตราส่วน 1:1 เป็น 1:2 และจากกราฟขาขึ้นเป็นกราฟขาลงหรือกราฟสองเส้น
6. คำถามย่อยอยู่ติดโจทย์และพื้นที่เขียนของตัวเอง ใส่คำชี้ทางสั้นเฉพาะจุดที่ช่วยเริ่มได้ เช่น “หาปริมาตรที่จ่ายในแต่ละรอบก่อนหาเฉลี่ย” ถ้าบทต้องพิสูจน์สูตรก่อนฝึก ให้เก็บชุดพิสูจน์และข้อสรุปการทดลองให้ครบก่อนเริ่มตัวอย่าง
7. ฉบับว่างเว้นเส้นหรือโครงตารางที่ครูต้องใช้ โครง ICF/ICE ยังมีชื่อสาร หน่วย และแถวให้เติม ฉบับเฉลยแสดงคำอธิบายและขั้นทำ ตารางที่ต้องใช้ผลจริงของแต่ละกลุ่มยังมีพื้นที่สำหรับค่านั้น

## 4. Exit Ticket · บทความและโจทย์

### บทความเติมคำจากการทดลอง

เขียนย่อหน้าเป็นเรื่องต่อเนื่อง โดยให้เด็กตามเหตุการณ์จากสิ่งที่ทำหรือสังเกต → คำและหลักการ → ข้อสรุปหรือขั้นถัดไป ลดประโยคที่ทำหน้าที่เพียงเชื่อมคำตอบ หยิบจุดที่เด็กสับสนมาเป็นตัวลวง เช่น จุดยุติกับจุดสมมูล หรือปริมาตรกับจำนวนโมล

- ต้นแบบมีบทความ A เรื่องบิวเรตและกราฟ และ B เรื่องผลวัด pH และบัฟเฟอร์ แต่ละชุดมี 6 ช่อง ใช้ **Word Bank 10 คำ** และ **Sentence Bank 4 ประโยค** บท A ใช้ 5 คำ + 1 ประโยค ส่วนบท B ใช้ 4 คำ + 2 ประโยค
- กำกับตัวเลือกด้วย `W01…` และ `S01…` ช่องตอบใช้ `A1…A6` หรือ `B1…B6` ใช้รหัสเดียวกันทั้งสองภาษา สลับตำแหน่งคำตอบในคลังให้เด็กต้องอ่านบริบท
- คลังคำวางสองคอลัมน์ภายในช่องของตัวเอง คลังคำและคลังประโยควางข้างกันบนจอใหญ่และกระดาษ จอเล็กเรียงลงมา ช่องคำอยู่ในประโยค ช่องเต็มประโยคกินความกว้างสำหรับเขียนตอบ
- ให้คำตอบที่เหมาะที่สุดหนึ่งคำหรือหนึ่งประโยคต่อช่อง ตรวจคำแทน สรรพนาม หน่วย และความกำกวมในทั้งสองภาษา ตัวลวงควรชวนให้ใช้เหตุผลจากเนื้อหา หลังเปิดเฉลยแสดงบทความที่เติมครบและเน้นคำหรือประโยคที่เติม

ตัวอย่างเขียนใหม่สำหรับตรวจรูปแบบ · “นักเรียนบันทึกสีที่เริ่มคงตัว ณ จุด `A1` หลังจากนั้นจึงใช้ปริมาตรที่อ่านเพื่อประมาณปริมาตรที่ทำให้กรดกับเบสทำปฏิกิริยาพอดี ซึ่งเป็นจุด `A2`” คลังคำควรมีจุดยุติ จุดสมมูล จุดครึ่งสมมูล และคำตัวลวงในบริบทเดียวกัน

### โจทย์ใหม่และแนวท้ายบท

- เขียนสถานการณ์ → สิ่งที่รู้พร้อมหน่วย → สิ่งที่ต้องหา ใช้ชื่อปริมาณในประโยคก่อนใช้ตัวแปร เช่น “จงหาความเข้มข้นเดิมของโซเดียมไฮดรอกไซด์” สูตรและเฉลยใช้สัญลักษณ์ที่นิยามแล้ว
- จัดข้อย่อยที่ใช้สถานการณ์เดียวกันไว้ด้วยกัน ให้ไต่จากอ่านค่า → จัดการข้อมูล → เลือกหลัก → อธิบายผล หากข้อหลังใช้คำตอบข้อก่อน ให้บอกชัดว่าข้อใด หากเปลี่ยนเป็นคนละสถานการณ์ ให้เขียนข้อมูลแยกให้ครบ
- ใส่พื้นที่ตอบติดแต่ละข้อย่อย ระบุคำกริยาตรงกับสิ่งที่จะตรวจ เช่น “ระบุ” “คำนวณ” “เขียนสมการไอออน” “เลือกและอธิบายจากกราฟ” ข้อคำนวณยาวควรมีพื้นที่สำหรับตารางและสมการหลายบรรทัด
- ต้นแบบข้อ 1–7 ไล่จากบิวเรตและสารส่วนเกิน → เกลือที่สมมูล → บัฟเฟอร์กรด → บัฟเฟอร์เบสและขีดจำกัด → เกลือจากกรดอ่อนและเบสอ่อน → อ่านกราฟและเลือกอินดิเคเตอร์ ใช้สารหรือตัวเลขคนละชุดกับตัวอย่างเมื่อจุดประสงค์คือวัดการนำไปใช้
- เมื่อยึดทักษะท้ายบท ให้ขึ้นป้าย **โจทย์แต่งอิงท้ายบท สสวท.** และบอกบทและเลขข้อที่ใช้อ้างอิง ต้นแบบอิงท้ายบท 10 ข้อ 5–14 โดยครอบคลุมเกลือ ยาลดกรด บัฟเฟอร์ และกราฟเบสอ่อน พร้อมชี้ว่าข้อ 1–4 ของหนังสือใช้ทวนทฤษฎีกรด–เบสและการแตกตัว [คู่มือครู สสวท. เคมี ม.5 เล่ม 4](https://www.scimath.org/ebook-chemistry/item/10299-4)
- เมื่อมีตัวเลขตรวจคำตอบ ให้แยก **Check Answer** จากวิธีทำ ในต้นแบบคำตอบปลายทางที่กำหนดให้ใช้ตรวจตนเองติดฉบับพิมพ์ผู้เรียน ส่วนวิธีทำยังซ่อนอยู่ โจทย์ A-Level ในต้นแบบตั้ง `printResult:false` เพื่อเก็บคำตอบจากผู้เรียนฉบับพิมพ์

## 5. Revision Notes · ใบที่นักเรียนอ่านทบทวน

ใช้ **Classroom Note ฉบับเฉลยกระชับจากต้นฉบับข้อมูลเดียวกัน** หัวข้อ นิยาม สูตร เลขสมการ ลำดับ รูป ตาราง ตัวอย่าง และคำตอบตรงกัน เปลี่ยนการจัดหน้าเพื่อลงชุด Exit ได้ ต้นแบบเรียกฟังก์ชัน `classroom(kit, true)` ใต้ `data-print-zone="learning"` ส่วน Classroom Note แยกเรียก `classroom(kit, false)`

ฉบับผู้เรียนของ Exit อ่าน Notes และตัวอย่างพาทำได้ครบ เพราะวิธีทำใน Notes คือบทเรียน เก็บวิธีทำเหล่านี้เป็นเนื้อหาที่มองเห็นทันทีและแยกจากเฉลยของข้อฝึกกับ Recall ตารางสำหรับผลแล็บจริงเปิดให้บันทึกค่าของแต่ละกลุ่ม ค่าจำลองในตัวอย่างระบุที่มาและเงื่อนไขของแบบจำลอง

ตรวจการใช้จริงด้วยโจทย์หนึ่งข้อจากแต่ละทักษะ เปิดเฉพาะฉบับผู้เรียนของ Exit แล้วลองหาข้อมูล สูตร หรือวิธีจาก Notes ถ้าต้องเปิดเว็บอื่นเพื่อเอาตัวเลขหรือกราฟที่จำเป็น ให้ใส่ข้อมูลนั้นไว้ในใบและคงลิงก์สำหรับอ่านต่อ

## 6. Knowledge Recall · ลองตอบจากความจำ

ใช้คำถามตรงกับสิ่งที่ต้องการให้เด็กเรียกคืน เช่น “ไฮโดรลิซิสของเกลือคืออะไร” “ไอออนใดรับโปรตอน” หรือ “จุดสมมูลอยู่ส่วนใดของกราฟ ให้ทำเครื่องหมาย” คำตอบหลักมักเป็นนิยามหนึ่งประโยค สมการหนึ่งบรรทัด คำอธิบายสั้น หรือการระบุจุดบนรูป

- เรียงจากนิยามและองค์ประกอบ → เงื่อนไขเลือกวิธี → อ่านรูปหรือกราฟ กราฟเปล่าของผู้เรียนต้องมีแกนและข้อมูลครบ ส่วนเฉลยค่อยแสดงป้ายที่ชี้คำตอบ
- ทำเลข Recall เป็นชุดของตัวเอง หากหลายข้อใช้รูปเดียว ให้ระบุ “ใช้กราฟในข้อ 3” หรือนำรูปไปไว้ร่วมกัน ป้องกันโจทย์อยู่หน้าเดียวแต่ขาดรูปที่ต้องใช้หลังแยกพิมพ์
- ตัวอย่าง 10.7–10.8 มีนิยามไทเทรต จุดยุติ จุดสมมูล บัฟเฟอร์ คู่กรด–เบส วิธีหาความเข้มข้นไฮโดรเนียมเมื่อ HCl เหลือ ไฮโดรลิซิส ครึ่งสมมูล ความสัมพันธ์ pH กับ pKₐ และช่วงสีอินดิเคเตอร์
- ให้พื้นที่ตอบตามงาน ข้อสั้นใช้บรรทัดสั้น ข้อระบุกราฟให้มีกราฟใช้งานได้ ฉบับเฉลยแสดงเหตุผลและกราฟประกอบตามจำเป็น ส่วนหน้าพิมพ์ผู้เรียนซ่อนเฉลย Recall ทั้งหมด

- พื้นที่คำตอบที่เปิด–ปิดได้ใช้ `data-sheet-slot` และ `data-sheet-answer` มี `data-sheet-placeholder` เมื่อใช้โครงตารางหรือเส้นจด กำหนดรหัส slot ตามความหมายและให้ TH/EN ใช้รหัสตรงกัน Notes ฉบับเฉลยที่ต้องอ่านเสมอเป็นเนื้อหาปกติ
- ใช้ `data-no-print` หรือ `.no-print` กับปุ่ม ลิงก์นำทาง และหัวจอที่ระบบจะสร้างใหม่ตอนพิมพ์ เก็บลิงก์อ้างอิงที่ผู้อ่านควรตามไว้ในเนื้อหา ใช้เครื่องมือภาษา เฉลย MathJax และพิมพ์ของ Hub ตาม [คู่มือใบเรียนรู้](README.md) สำหรับรูปแบบเก่าที่แบ่งหน้าไว้แล้ว ให้ตรวจ adapter ของไฟล์นั้นก่อนเปลี่ยน marker

## 10. ตรวจรับก่อนส่งและพรอมป์ต์สำหรับเริ่มหัวข้อถัดไป

| ตรวจ | ต้องเห็นอะไร |
| --- | --- |
| แหล่งข้อมูลและวิชา | มีลิงก์และหน้าของต้นฉบับ ข้อมูลในกราฟครบ คำนวณทุกคำตอบใหม่ ตรวจคำตอบและลำดับตัวเลือกกับชุดเดิม |
| โยงระหว่างชุด | ทุก Exit มีแหล่งเรียนรู้หรือวิธีใน Note ประโยคและตัวเลขของ Revision Notes ตรงกับ Classroom ฉบับเฉลย ทั้งสองภาษา |
| เว็บและการพิมพ์ | เปิดจาก route จริง สลับ TH/EN ได้ เปิดเฉลยรายข้อและเปิด/ปิดทั้งหมดได้ รูปพร้อม สูตรเรนเดอร์ แบ่งหน้าตรงโซน และฉบับว่างแสดงเฉพาะ Check Answer ที่ตั้งไว้ |
| A4 | ตรวจช่วงละฉบับทั้ง TH และ EN เลขหน้าตรง จำนวนหน้าระหว่าง preview กับ PDF ตรง ช่องเขียนเพียงพอ รูปและข้อความอยู่ภายในหัว–ท้าย |
| เทคนิค | รัน `pnpm validate:content` และการทดสอบการพิมพ์ที่เกี่ยวข้อง เช่น `node --test scripts/html-print.test.mjs scripts/learning-sheet.test.mjs` หากลง Hub ให้ตรวจ build, route และตัวอย่างก่อนพิมพ์ใน Chromium พร้อมบันทึกผล Safari/iPad หรือเครื่องพิมพ์จริงเมื่อได้ใช้จริง |
