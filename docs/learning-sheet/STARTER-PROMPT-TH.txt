อ่านพรอมป์ต์นี้ร่วมกับรายละเอียดบทใหม่ที่ครูจะส่งต่อท้าย ยังไม่ให้เลือกบทหรือสร้างไอดีคลังขึ้นเอง

ก่อนเริ่ม
1. ใช้ main ล่าสุดและอ่าน AGENTS.md ที่เกี่ยวข้องถ้ามี ตรวจงานค้างและไฟล์ที่ผู้ช่วยอื่นรับผิดชอบ
2. อ่าน docs/learning-sheet/README.md ให้ครบ
3. อ่าน LEARNING-SHEET-START-HERE.txt, public/content/templates/learning-sheet-ai-prompt.txt และ public/content/templates/bank-id-authoring-guide.txt
4. อ่าน HTML ตัวอย่างหลัก public/content/physics/ipst/wave-optics/10-2-double-slit-learning-sheet.html และเมนู public/content/bank/physics/b-21460452889578f11c3a8bac.html
5. ถ้ามีการทดลอง ให้อ่านตัวอย่าง public/content/physics/ipst/equilibrium/4-2-centre-of-mass-learning-sheet.html
6. ยืนยันชื่อหัวข้อ subjectId, path, legacyId ถ้ามี และ bankKey จากหัวข้อ/catalog จริง พร้อมอ่านเมนูเดิมของไอดีเป้าหมาย ห้ามคำนวณ hash เองหรือใช้ ID ตัวอย่างแทน
7. อ่านต้นฉบับช่วงที่ครูระบุจริง แยกหน้าหนังสือกับหน้า PDF ตรวจข้อความ รูป คำบรรยาย ตาราง กิจกรรม ตัวอย่าง คำถามและแบบฝึกหัด รวมคู่มือครูที่ให้

สไตล์ที่ต้องทำให้ได้
- มีหัวข้อเนื้อหาจริงและพื้นที่ให้นักเรียนเขียนสาระสำคัญ ไม่ทำเป็นชีทอ่านหนาแน่นหรือคำถามล้วน
- สลับหัวข้อความรู้ ภาพ คำถามสั้น ตัวอย่างและโจทย์ตามลำดับการเรียนรู้ เพิ่มคำถามให้ค่อย ๆ ทำได้ ไม่กระโดดไปโจทย์รวมทันที
- ทุกข้อ/ข้อย่อยมีพื้นที่ตอบของตัวเองอยู่ใต้ข้อนั้น กำหนดขนาดตามงานเขียนและขั้นคำนวณ ยอมเพิ่มหน้าได้
- ส่วนทดลองใช้ภาพเริ่มต้น → ผลที่สังเกต → คำถาม → สรุปผลและเนื้อหาที่เกี่ยวข้อง ให้ภาพเป็นชุดที่สัมพันธ์กัน
- ไม่ใช้ป้ายแต่งเพิ่มว่า จุดเช็ก / เช็กความเข้าใจ / จด / จำ / ฝึกเพิ่ม หรือคำแปลของป้ายเหล่านี้ ใช้หัวข้อเนื้อหา ตัวอย่าง และเลขคำถามธรรมดา ชื่อชุดคำถามทางการจากต้นฉบับระบุได้
- คำถามที่เพิ่มนับต่อเนื่องทั้งไฟล์ ตัวอย่างนับแยก อย่าใช้จำนวนหน้า/คำถามของตัวอย่างเป็นโควตาบทใหม่
- TH/EN เป็นสองชุดเต็มที่ตรงกันทั้งข้อย่อย รูป ตัวเลข สูตรและเฉลย ไม่สลับคละย่อหน้า
- เฉลยครบทั้งหัวข้อความรู้และโจทย์ มีเหตุผล ขั้นคำนวณ หน่วย เงื่อนไข และการประมาณที่เหมาะสม
- ใช้รูปที่มีจริงจากต้นฉบับหรือแหล่งที่เหมาะสม แผนภาพที่ต้องแม่นยำใช้รูปต้นฉบับ/SVG/โค้ดที่ตรวจได้ เก็บ assets พร้อม SOURCES.md

ผลลัพธ์และขอบเขต
- HTML ใบเรียนรู้กับ assets ของหัวข้อ และเพิ่ม/แก้ anchor ใน public/content/bank/<subjectId>/<real-bankKey>.html โดยรักษารายการอื่น
- ใช้ data-learning-html data-learning-sheet="1" และ data-sheet-slot/data-sheet-answer ตามสัญญาเดิม สองภาษาใช้ semantic slot key เป็นคู่
- learning-sheet เป็น data-tool-kind="html"; contentId คงที่และไม่ซ้ำ tool-key ของใบเดิมต้องรักษา หากมีหลายใบให้ตั้ง key ใหม่ที่ไม่ชน
- ใช้ภาษา เฉลย MathJax และพิมพ์จาก Hub เดิม ไม่เพิ่ม script/toolbar/ปุ่มพิมพ์/engine หรือแก้ฐานข้อมูล/Apps Script/ไฟล์กลางเพื่อทำใบนี้
- ไม่ใช้ data-review-* ของ Topic Review แทน data-sheet-* ไม่เปลี่ยนชนิดเครื่องมือของงานโดยพลการ
- relative path ของ CSS, รูป และเมนูต้องตรงระดับโฟลเดอร์จริง ไม่คัดลอกไอดี ชื่อเรื่อง สูตรหรือรูปของตัวอย่างติดมาบทใหม่
- ทำ branch แยกหัวข้อ ตรวจ main/diff ล่าสุดก่อนรวมงาน ไม่เขียนทับงานผู้ช่วยอื่น

วิธีดำเนินงาน
1. ส่งบัญชีเนื้อหาและแผนแต่ละช่วง พร้อมสิ่งที่จะให้นักเรียนเขียน คำถาม รูป และข้อจากหนังสือที่ครอบคลุม
2. ถ้าครูสั่งวางแผนก่อน ให้หยุดที่แผนก่อนลงมือ ถ้าสั่งลุยหรือให้ทำแล้ว ให้ดำเนินต่อจนเสร็จโดยไม่ตั้งขั้นขออนุมัติซ้ำทุกช่วง
3. ทำเป็นช่วงต่อกันในไฟล์เดียวตามขอบเขตที่ตกลง ไม่แยกไฟล์เพียงเพราะงานยาว
4. ตรวจคำตอบด้วยตนเองและคำนวณใหม่ ตรวจความครบของต้นฉบับและ TH/EN
5. ใช้ QA-CHECKLIST.md รันตรวจโครงสร้าง/build ที่เกี่ยวข้อง เปิด Hub ตรวจภาษา ปุ่มเฉลย รูป สูตร และช่องตอบ แล้วตรวจฉบับพิมพ์ TH/EN × ว่าง/เฉลย
6. แยกหลักฐาน central print preview, PDF ที่ export จริง และ native iPad/Safari ห้ามอ้างว่าได้ทดสอบสิ่งที่ยังไม่ได้ทำ
7. เผยแพร่ตามสิทธิ์ที่ครูอนุญาตในแชท ตรวจ Actions และเว็บจริงก่อนแจ้งว่าขึ้นแล้ว ถ้าขาดสิทธิ์/runtime ให้ส่งไฟล์หรือ patch ที่พร้อมวาง พร้อมผลตรวจจริงและสิ่งที่ต้องตรวจต่อ

ถ้าต้นฉบับ repo รูป หรือ ID อ่านไม่ได้ ให้บอกจุดที่ติดตามจริง ตรวจจากแหล่งที่มีและทำส่วนอิสระต่อ ถามเฉพาะข้อมูลจำเป็นที่หาไม่ได้ ไม่แต่งลิงก์ รูป bankKey แหล่งอ้างอิง หรือผล QA

ส่งกลับครู: เรื่อง/ไอดีคลัง, ไฟล์ที่เปลี่ยน, เนื้อหาและคำถามที่ครอบคลุม, สิ่งที่เพิ่ม, ผล QA/ข้อจำกัด, สถานะเผยแพร่ และลิงก์ตรงที่ตรวจแล้วเมื่อเผยแพร่สำเร็จ

รายละเอียดบทใหม่อยู่ในข้อความที่ครูส่งต่อจากพรอมป์ต์นี้
