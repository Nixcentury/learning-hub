## แม่แบบและการสร้าง

การอ่านภาพเป็นกิจกรรมใช้แนวเคมี 2.5 ส่วนการใช้ฉบับเฉลย Classroom Note เป็นต้นฉบับของ Revision Notes ใช้แนวสลิตคู่ 10.2 v1.3 เรียก `node docs/learning-sheet/preparation/chemistry-radioactive-elements-2-7/build.mjs` จากราก repo เพื่อสร้าง HTML ทั้งสองจาก `notes.mjs`, `exercises.mjs` และ `paired.css`

Classroom Note มีคำถามชวนสังเกตและ 5 ตัวอย่างพาทำ ฉบับช่องเขียนมีพื้นที่ให้ครูสาธิตบน iPad ฉบับเฉลยเขียนความสัมพันธ์และขั้นแทนค่าพร้อมหน่วย สำหรับ Exit ทั้งสองฉบับใช้ Notes ชุดเดียวกันและเพิ่ม 2 บทอ่านเติมคำ, 8 ข้อหลัก, Recall และ 1 ข้อเสริม นักเรียนเปิด Notes และตัวอย่างได้ครบ ส่วนฉบับฝึกมีพื้นที่เปล่ารายข้อย่อย

| เอกสาร | ทั้งชุด | ช่วงโจทย์ | ช่วง Notes |
|---|---:|---:|---:|
| Classroom Note | 8 | 3 · ตัวอย่างพาทำ | 5 · บทเรียน |
| Exit Ticket Revision | 15 | 7 · แบบฝึกและ Recall | 8 · Revision Notes |

จำนวนหน้าต่อภาษาเท่ากันในฉบับช่องเขียนและเฉลย ชื่อ–ห้องบนหน้าแรกของแต่ละช่วง 8 pt เนื้อหา 10 pt หัวข้อ 11 pt
