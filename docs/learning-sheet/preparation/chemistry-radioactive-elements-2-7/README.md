## แม่แบบและการสร้าง

การอ่านภาพเป็นกิจกรรมใช้แนวเคมี 2.5 ฉบับ v1.1 ใช้ลำดับและการจัดสมการตามสลิตคู่ 10.2 โดยเรียงบทอ่านเติมคำ โจทย์หลักและโจทย์เสริม Revision Notes แล้วปิดด้วย Knowledge Recall บทอ่านใช้ช่อง A1–A5 และ B1–B2 ในเนื้อเรื่อง ข้อเขียนตอบแต่ละข้อย่อยมีพื้นที่ของตัวเอง

ติดตั้ง MathJax 3.2.2 ด้วย `npm ci --prefix tools/pdf-authoring` แล้วเรียก `node docs/learning-sheet/preparation/chemistry-radioactive-elements-2-7/build.mjs` จากราก repo ตัวสร้างใช้ `notes.mjs`, `exercises.mjs`, `math.mjs` และ `paired.css` เพื่อสร้าง HTML v1.1 ทั้งสองไฟล์และสมการ SVG ใน `assets/2-7-radioactive/math/`

Classroom Note มีคำถามชวนสังเกตและ 5 ตัวอย่างพาทำ ฉบับช่องเขียนมีพื้นที่ให้ครูสาธิตบน iPad ฉบับเฉลยเขียนความสัมพันธ์และขั้นแทนค่าพร้อมหน่วย สำหรับ Exit ทั้งสองฉบับใช้ Notes ชุดเดียวกันและเพิ่ม 2 บทอ่านเติมคำ, 8 ข้อหลัก, Recall และ 1 ข้อเสริม นักเรียนเปิด Notes และตัวอย่างได้ครบ ส่วนฉบับฝึกมีพื้นที่เปล่ารายข้อย่อย

| เอกสาร | ทั้งชุด | ช่วงโจทย์ | ช่วง Notes |
|---|---:|---:|---:|
| Classroom Note ทั้งสองฉบับ | 8 | 3 · ตัวอย่างพาทำ | 5 · บทเรียน |
| Exit Ticket Revision · นักเรียน | 15 | 7 · แบบฝึกและ Recall | 8 · Revision Notes |
| Exit Ticket Revision · เฉลย | 16 | 8 · แบบฝึกและ Recall | 8 · Revision Notes |

จำนวนหน้าตรงกันระหว่าง TH/EN ฉบับเฉลยแยกข้อ 5 และ 6 เพื่อให้เศษส่วนและวิธีทำอ่านง่าย ชื่อ–ห้องบนหน้าแรกของแต่ละช่วง 8 pt เนื้อหา 10 pt หัวข้อ 11 pt
