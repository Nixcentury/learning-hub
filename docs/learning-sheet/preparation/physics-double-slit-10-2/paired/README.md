| Classroom Note เฉพาะทฤษฎี | 6 | 6 |

| Exit Ticket ทั้งชุด | 21 | 26 |
| Exit Ticket ควิซรวม Recall | 9 | 14 |
| Exit Ticket เฉพาะ Revision Notes | 12 | 12 |

Exit Ticket v1.3.1 เพิ่มหนึ่งหน้าท้ายชุดโจทย์สำหรับข้อฝึกแยกความสว่างจากตำแหน่งแถบตามแบบฝึกหัด สสวท. 10.2 ข้อ 2 ค และข้อสอบ A-Level ฟิสิกส์ ชุด 1 ปี 2566 ข้อ 11 และปี 2568 ข้อ 9 มีลิงก์เปิดข้อสอบ ช่องตอบ และเฉลยให้เปิดด้วยระบบเดิม

จำนวนหน้าที่กำหนดตรงกันทั้ง TH/EN ฉบับเฉลยแยกวิธีทำเต็มความกว้างหน้าและแสดงสมการเริ่มต้น จึงมีหน้ามากกว่าฉบับทำโจทย์ ไม่ย่อฟอนต์เพื่อบีบหน้า: ชื่อและห้อง 8 pt เฉพาะหน้าแรกของช่วงที่เลือก; เนื้อหา 10 pt; หัวข้อ 11 pt พื้นที่เขียนไม่มีเส้นหรือจุด

## ลำดับการสอน

1. ทบทวนสั้น ๆ ว่าแสงสองขบวนจากสลิตคู่แทรกสอดเป็นแถบสว่างและมืด แล้วเปิดแล็บโหมด **แสง · วัดแถบ**
2. เปลี่ยนทีละตัว: ระยะสลิต ความยาวคลื่น และระยะฉาก โดยคุมตัวอื่นคงที่ สรุปผลเป็นข้อความก่อนแสดงสูตร แล้วถามว่าจะอธิบายผลด้วยหลักแทรกสอดอย่างไร
3. ใช้รูปนิยามตัวแปรก่อนเริ่มพิสูจน์ แยกข้อความกับสมการทีละบรรทัด พิสูจน์สูตรครบก่อนตัวอย่างแรก ตีกรอบสมการสำคัญ ณ จุดที่ได้มาและกำกับเลข (1)–(15)
4. กลับมาอธิบายผลทดลองทั้งสามด้วยสมการ (9) และอัตราส่วน (10)–(12) ก่อนทำตัวอย่าง ใช้ Δx แทนระยะห่างแถบตลอดบท แยกจากพิกัดแถบ ไม่ใช้ β เพิ่มอีกสัญลักษณ์
5. เฉลยเริ่มด้วย **ใช้สมการ (…) → เขียนสมการสัญลักษณ์ → จัดรูป/แทนค่า → คำนวณ → คำตอบและหน่วย** เลือกชนิดแถบก่อนหาอันดับ ตรวจจำนวนเต็มและเงื่อนไขที่ใช้ ห้ามปัดอันดับเอง

คงตัวอย่างเดิม 12 ข้อ บทความเติมคำ 2 ชุด โจทย์ใหญ่ 9 ข้อ และ Recall 4 กลุ่ม (14 ข้อย่อย) ข้อมูลตัวเลข คำถาม และการคำนวณเดิมยังครบ ใช้ Revision Notes ฉบับครูเดียวกันใน Exit ทั้งสองฉบับ ปิดเฉลยใน Classroom เพื่อเขียนสาธิตได้ตามเดิม

## ต้นฉบับและการสร้างใหม่

`notes.mjs` ประกอบ canonical Notes ชุดเดียวสำหรับ Classroom และ Revision โดยคำนวณ hash รวมแหล่งเนื้อหา 7 ไฟล์:

| ไฟล์ | หน้าที่ |
| --- | --- |
| `notes.mjs` | ประกอบหน้าและจัดกลุ่มตัวอย่าง |
| `intro-v1.3.json` | บทนำ การทดลองควบคุม และข้อสรุปก่อนสูตร สองภาษา |
| `proofs.mjs` | นิยาม พิสูจน์ สมการ (1)–(15) และคำอธิบายผลทดลอง |
| `note-diagrams.mjs` | รูปประกอบการวัดและตัวอย่าง 10–12 พร้อมป้ายสมการ TeX ที่แปลงเป็นเส้นเวกเตอร์ด้วย MathJax |
| `proof-figures.json` | รูปเรขาคณิตและตำแหน่ง/ระยะห่างแถบ |
| `examples-v1.2.json` | สำเนาตัวอย่างเดิม 12 ข้อต่อภาษา สำหรับรักษาโจทย์และวิธีคำนวณ |
| `equation-starts.mjs` | อ่านสมการจริงจากทฤษฎีมาเริ่มเฉลยและแบ่งบรรทัด ไม่เก็บสูตรซ้ำอีกชุด |

`exit-exercises.json` เป็นโจทย์และเฉลยเดิม **ไม่ได้แก้ไฟล์ในรอบ v1.3** ตัวสร้างเพิ่มเลขสมการและบรรทัดวิธีทำผ่าน `prepareExerciseWorking` ส่วน `paired.css` เก็บรูปแบบพิมพ์ `build.mjs` สร้าง HTML static และสมการ SVG ใน `assets/10-2-paired` ต้องเรียก `normalize()` ก่อนอ่าน text nodes ที่อาจถูกแยกด้วยเครื่องหมาย `&` ของ aligned เพื่อไม่ทำสมการหาย และตรวจว่าไม่มี TeX ค้างหลังสร้าง

ผลจำนวนหน้าและ hash รอบนี้อยู่ใน `build-record-v1.3.json` ฟอนต์ 4 ไฟล์มาจากต้นฉบับผู้ใช้ รูปหนังสือใช้ crop เดิมตาม `assets/10-2/SOURCES.md` สร้างไฟล์สาธารณะชื่อ `*-v1-3.html` เก็บ v1/v1-1/v1-2 และ assets เดิมไว้

ใช้ dependencies หลักของ repo และ MathJax 3.2.2 จาก `tools/pdf-authoring/package.json`:

```sh
node docs/learning-sheet/preparation/physics-double-slit-10-2/paired/build.mjs
node --test scripts/double-slit-paired.test.mjs scripts/content-tool.test.mjs
pnpm test:unit
pnpm build
```

กำหนด `HUB_MATHJAX_ROOT` ได้หากติดตั้ง MathJax นอกที่ตั้งปกติ ไม่ต้องใช้เบราว์เซอร์สร้างสมการ การแบ่งหน้ากำหนดใน build และต้องตรวจพิมพ์จริงในเบราว์เซอร์หลังเปลี่ยนเนื้อหา ผล offline ไม่ทดแทนการตรวจ Hub/Chromium/iPad จริง
