# 10.2 สลิตคู่ — Classroom Note และ Exit Ticket Revision

Classroom Note ใช้ครูสาธิตและเขียนเพิ่มบน iPad ไม่ต้องพิมพ์แจกซ้ำ นักเรียนใช้ Exit Ticket Revision ซึ่งมี Classroom Note **ฉบับเฉลยครบทั้ง 9 หน้า** เป็น Revision Notes อยู่แล้ว การปิดเฉลยซ่อนเฉพาะคำตอบแบบฝึก ไม่ซ่อนตัวอย่างอ่านใน Notes

- Classroom Note: 9 หน้า มีคำถามสังเกตสั้นและตัวอย่าง 12 ข้อ เลือกฉบับช่องเขียนหรือฉบับเฉลย และเลือกทั้งชุด/เฉพาะตัวอย่าง/บทเรียนกับกิจกรรมสังเกตได้
- Exit Ticket Revision: ทั้งชุด 17 หน้า; ควิซรวม Recall 8 หน้า; Notes 9 หน้า ทั้ง TH/EN และทั้งสองฉบับมีจำนวนหน้าเท่ากัน
- คงบทความเติมคำ 2 ชุด โจทย์ใหญ่ 9 ข้อ และ Recall 4 กลุ่ม เพิ่ม Recall เรื่องเฟสและแถบสองสีซ้อนกัน รวม 14 คำถามย่อย
- ชื่อและห้องเท่านั้น 8 pt ใต้ชื่อเอกสาร หน้าแรกของแต่ละช่วงที่เลือกพิมพ์; เนื้อหา 10 pt หัวข้อ 11 pt ไม่มีกรอบข้อมูลส่วนตัว
- โจทย์ตัวเลข: ความสัมพันธ์/สมการ → แทนค่า → คำตอบและหน่วย ใช้หน่วยที่สอดคล้องก่อนแทนค่า ไม่ต้องตัดหน่วยทุกบรรทัด

## ใช้ในคาบ

เปิด Classroom Note ปิดเฉลยเพื่อเขียนสาธิต หรือเปิดเฉลยเป็นฐานแล้วอธิบายเพิ่ม ให้เด็กสังเกตและตอบปากเปล่าสั้น ๆ ก่อนทำ Exit Ticket เด็กอ่าน Notes ที่พิมพ์รวมมาประกอบได้ ไม่ต้องคัดตามทั้งบท หลังทำโจทย์ใช้ Recall ทวนความสัมพันธ์ที่ต้องจำ แล้วฝึกต่อด้วยชุดทบทวน 50 ข้อเดิม

ลิงก์ใน Hub:

- `#physics/bank/double-slit-interference/classroom-note`
- `#physics/bank/double-slit-interference/exit-ticket-revision`

ปุ่มทั้งสองใช้ตัวเปิด HTML ภาษา เฉลย และพิมพ์ A4 ของ Hub ที่มีอยู่ แยกจากการให้คะแนน ไม่เพิ่มระบบทำข้อสอบหรือระบบพิมพ์ใหม่ ปุ่มใบเรียนรู้เดิม ชุดทบทวน 50 ข้อ คลิป และแล็บยังอยู่

## ต้นฉบับและการสร้างใหม่

`notes.mjs` เป็นแหล่งเนื้อหา Notes สองภาษาเพียงแห่งเดียว ทั้ง Classroom Note ฉบับเฉลยและ Revision ของนักเรียน/ครูสร้างจาก HTML ชุดเดียวกัน มี hash กำกับ ปรับเนื้อหาที่นี่แล้วสร้างทั้งคู่พร้อมกัน ห้ามแก้ Notes ในไฟล์สาธารณะแยกกัน

`exit-exercises.json` เก็บส่วนโจทย์จากไฟล์ที่ผู้ใช้ส่ง พร้อมการแก้ไขตามรายการด้านล่าง `paired.css` เก็บรูปแบบพิมพ์ `build.mjs` สร้าง HTML แบบ static และสมการ SVG ใน `assets/10-2-paired` ผลจำนวนหน้าและ hash อยู่ใน `build-record.json` ฟอนต์ 4 ไฟล์สกัดจากต้นฉบับที่ผู้ใช้ให้ รูปหนังสือใช้ crop เดิมตาม `assets/10-2/SOURCES.md`

ใช้ dependencies ของเครื่องมือ PDF เดิม (MathJax 3.2.2, ดู `tools/pdf-authoring/package.json`) และ dependencies หลักของ repo:

```sh
node docs/learning-sheet/preparation/physics-double-slit-10-2/paired/build.mjs
node --test scripts/double-slit-paired.test.mjs
pnpm build
```

ถ้าติดตั้ง MathJax ไว้นอกที่ตั้งปกติ กำหนด `HUB_MATHJAX_ROOT` ไปยังโฟลเดอร์ `mathjax-full` ได้ ไม่ต้องใช้เบราว์เซอร์สร้างสมการ การแบ่งหน้าระบุไว้ใน build และต้องวัดจริงในเบราว์เซอร์หลังเปลี่ยนเนื้อหา

## หลักการหลังครูตรวจรอบนี้

เก็บรูปและพิสูจน์สูตรใหม่เต็มขั้นใน Classroom Note ให้ครูแสดง ไม่ให้เด็กคัดพิสูจน์ตาม เพิ่มเหตุผลสั้น ๆ ในเฉลย แล้วนำฉบับเฉลยเดียวกันทั้งชุดไปวางใน Revision ทั้งสองภาษา โจทย์เขียนชื่อปริมาณเต็ม ส่วนสมการและเฉลยใช้สัญลักษณ์ได้ พื้นที่แสดงวิธีทำขยายตามพื้นที่ว่างของหน้าที่มีโจทย์และ Recall ไม่ใส่เส้นหรือจุด ข้อย่อยต่อหน้าถัดไปได้เมื่อจัดหน้าใหม่ในอนาคต

`proofs.mjs` และ `proof-figures.json` เป็นส่วนของ canonical Notes ด้วย โดยคืนแผนภาพเดิมจากไฟล์ R03 ที่ครูให้ไว้ hash ของ Notes คำนวณรวมทั้งสามไฟล์
