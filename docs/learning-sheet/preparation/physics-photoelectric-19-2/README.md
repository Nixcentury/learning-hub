The teaching sweep first reaches zero at −0.50 V, with a positive reading at −0.45 V. The adjacent readings bracket the stopping-potential magnitude; the model's cutoff for the teaching preset is exactly 0.50 V. The graph axis uses signed V, whereas equation (4) uses the positive magnitude. Students can use the Exit Ticket problems on paper because all required data are printed alongside them.
