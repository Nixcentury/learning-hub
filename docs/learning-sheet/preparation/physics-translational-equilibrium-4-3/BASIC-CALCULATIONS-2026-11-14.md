## สไตล์เฉลยตามรูปที่ครูส่ง

เขียนโจทย์ทุกข้อเป็นประโยคเต็ม ระบุสถานการณ์ ปริมาณที่ให้ และสิ่งที่ถาม ไม่ทำเป็นรายการตัวแปร วาดแผนภาพแรง SVG ขาวดำ ระบุหัวลูกศร แกนและแนวอ้างอิงมุมให้ชัด ให้เลือกวัตถุหรือปมที่พิจารณาก่อนเขียนแรง

เฉลยเรียง **รูปแรง → แตกแรง → สมการแกน x และ y พร้อมหมายเลข (1), (2) → แก้สมการ → แทนค่า → คำตอบพร้อมหน่วย** เมื่อไม่ทราบทั้งขนาดแรงและมุม ให้หารสมการเพื่อตัดขนาดแรง หามุมก่อน แล้วแทนกลับหาขนาดแรง เมื่อมุมทราบและไม่ทราบแรงสองแรง ให้แทนสมการเข้าหากันตามเหมาะสม ไม่ฝืนหารทุกข้อ

- แสดงสูตร จัดรูป และแทนค่าใน MathJax `aligned` ไม่ข้ามไปเฉพาะคำตอบหรือใช้สูตรลัดแทนวิธีทำ
- ใส่คำอธิบายไทย–อังกฤษไว้นอกสมการ ใช้หน่วยตัวตรงและกล่องคำตอบ
- มุมวัดจากแนวนอนหรือแนวดิ่งทำให้ sin/cos ต่างกัน ให้อธิบายตามรูป ไม่ท่องว่าแนวระดับเป็น cos ทุกครั้ง
- ขนาดองค์ประกอบบนลูกศรใช้ค่าบวกตามป้าย ใส่เครื่องหมายขององค์ประกอบในสมการตามทิศแกน ไม่รวมแรงเต็มซ้ำกับองค์ประกอบ
- ข้อ 1 ใช้ข้อมูลที่ครูส่ง: แรง 10 N ทางขวา และแรง 10 N ที่ 120° จาก +x ได้แรงสมดุลลงซ้าย ต้องแยกมุม 60° ต่ำกว่าแนวซ้ายจากมุมทิศทาง 240° จาก +x
- ข้อ 2 หามุมจากแนวดิ่ง ให้คงค่ามุมเต็มในเครื่องคิดเลขก่อนปัดคำตอบ
- ไม่เพิ่มจำนวนข้อเกิน 6 โดยอัตโนมัติ ไม่เพิ่มพิสูจน์ยาวหรือโจทย์หลายเงื่อนไขให้ยากขึ้น
- คง 6 semantic slot keys และลำดับ TH/EN ตรงกัน ระบบกลางเป็นผู้สร้างปุ่มภาษา เฉลย ไกด์ และพิมพ์ ไม่เพิ่มสคริปต์หรือ toolbar ในเนื้อหา
- รูปประกอบ SVG เป็นภาพเขียนใหม่ ไม่ใช้ภาพจากหนังสือหรือภาพลายมือของครูเป็น asset ของเว็บ ตัวอักษรในรูปและลูกศรต้องไม่ชนหรือถูกตัด และ ID ภายใน SVG ต้องไม่ซ้ำข้ามภาษา
- พิมพ์ขาวดำ หัวข้อ 12 pt เนื้อหา 10 pt ไม่มีช่องชื่อ/ชั้นและไม่มีเส้นบรรทัดอัตโนมัติ ย่อรูปบนกระดาษโดยยังอ่านป้ายได้
- คง CSS เฉพาะหน้าพิมพ์ที่จัดรูปข้างสมการ ใช้ 10 pt / line-height 1.4 และระยะ display math กระชับ ช่องเฉลยในระบบกลางเป็นก้อนที่ต้องพอดีหน้า อย่าครอบทั้งคำถามและเฉลยด้วย `data-print-keep` หรือเพิ่มรายละเอียดจนเฉลยหนึ่งช่องเกินหน้ากระดาษ ฉบับว่างสำรองพื้นที่เท่ากับเฉลยตามระบบกลาง

แยกให้ชัดว่า **สูตรหลักที่ตั้งขึ้นในหัวข้อ 4.3 คือเงื่อนไขสมดุลและสมการแกน** ส่วน W = mg, ตรีโกณมิติ และกฎแรงเสียดทานเป็นความรู้พื้นฐานที่นำมาใช้ กรอบสูตรจึงมีทั้งสูตรหลักและพื้นฐานประกอบ ไม่อ้างว่า μsN/μkN เป็นสมการใหม่ที่พิมพ์ในหัวข้อ 4.3 หน้า 11–24

ในหน้าที่ตรวจนี้ไม่ได้ตั้งกฎไซน์/โคไซน์เป็นสมการหลักของ 4.3 จึงยึดการแตกแรงและสมการสองแกนตามคำขอครู แรงเสียดทานสถิตจริงต้องหาโดยสมดุลก่อนแล้วจึงตรวจ 0 ≤ fs ≤ μsN; ใช้ fs = μsN เฉพาะจวนไถล พื้นเอียงให้ใช้ N = mg cos α เฉพาะแบบจำลองไม่มีแรงอื่นในแนวตั้งฉากกับพื้น

โจทย์ชุดนี้แต่งเลขง่ายเพื่อฝึกทักษะ ไม่อ้างว่าเป็นสำเนาข้อสอบหรือถอดโจทย์ สสวท. ทุกข้อ รูปต้นฉบับและไฟล์หนังสือไม่ถูกเพิ่มเข้า repository
