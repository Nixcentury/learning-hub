# 4.3 ฝึกคำนวณ: คำตอบตรวจตนเองบนกระดาษ

เพิ่มคำตอบสุดท้ายครบทั้ง 6 ข้อ TH/EN ในฉบับพิมพ์ว่างและเฉลย เพื่อให้ผู้เรียนตรวจคำตอบได้เอง ฉบับอ่านปกติยังซ่อนคำตอบสั้น ส่วนวิธีทำเต็มยังเปิดได้ตามระบบใบเรียนรู้

## ตำแหน่งและการรักษาเนื้อหา

ใช้แถบคำบรรยายใต้รูปโจทย์เดิมเป็นพื้นที่คำตอบ 10 pt โดยแสดงคำบรรยายรูปเดิมเมื่ออ่านบนจอ และแสดงคำตอบสั้นแทนคำบรรยายเมื่อพิมพ์ ข้อมูลและมุมที่จำเป็นยังอยู่ครบในข้อความโจทย์และรูป ไม่ลดขนาดรูป ไม่ลดพื้นที่แสดงวิธีทำ และไม่เพิ่มข้อ โจทย์ รูป SVG และวิธีทำทั้ง 6 ข้อตรงกับฉบับก่อนแก้ทุกประการ

คำตอบสั้นอยู่ภายนอก `data-sheet-answer` จึงยังอยู่ในฉบับว่าง ส่วนเฉลยละเอียดถูกแทนด้วยพื้นที่เขียนจริง เก็บฉบับก่อนแก้ที่ `basic-calculations-before-print-self-check.html` ในโฟลเดอร์นี้ ไม่เพิ่มสำเนา public ที่ไม่มี catalog

Revision `2026-11-16-1`; อัปเดต guide revision/fingerprint และคำแนะนำตรวจคำตอบหลังแสดงวิธีทำ

## ประเมินว่าควรเพิ่มโจทย์หรือไม่

ชุดนี้เป็นใบฝึกพื้นฐาน 6 ข้อ ตามขอบเขตเดิม ไม่ใช่ใบรวมโจทย์สอบครบทั้งบท:

| ข้อ | ทักษะที่มีแล้ว |
| --- | --- |
| 1 | แรงที่ทำให้สมดุล องค์ประกอบมีเครื่องหมาย และควอดแรนต์ของมุม |
| 2 | มุมจากแนวดิ่ง หามุมก่อนหาความตึงเชือก |
| 3 | ปมเชือกสองเส้นต่างมุมและความตึงไม่เท่ากัน |
| 4 | ความเร็วคงตัว แรงดึงเอียง แรงแนวฉากและแรงเสียดทานจลน์ |
| 5 | เลือกแกนพื้นเอียง แรงเสียดทานสถิตจริงเทียบค่าสูงสุด |
| 6 | ใช้เรขาคณิตของเชือกหาระยะและอัตราส่วนก่อนตั้งสมการแรง |

ข้อเสนอที่คุ้มพื้นที่ที่สุดคือข้อย่อยต่อข้อ 5 เกี่ยวกับ **สัมประสิทธิ์ความเสียดทานสถิตต่ำสุด** เช่น “หากเปลี่ยนผิวสัมผัสโดยคงมุมพื้นเอียง 30° สัมประสิทธิ์ความเสียดทานสถิตต้องมีค่าอย่างน้อยเท่าใด กล่องจึงยังอยู่นิ่งได้” ใช้รูปและข้อมูลเดิม และฝึกเงื่อนไขจวนไถลที่ยังไม่ได้ถามโดยตรง:

`fs ≤ μs N → μs ≥ fs/N = 10/(10√3) = 1/√3 ≈ 0.577` (ไม่มีหน่วย)

หากจะขยายเกินใบพื้นฐานในอนาคต จึงพิจารณาแรงตึงเชือกสูงสุดก่อนขาดหรือช่วงแรงที่ยังสมดุลได้ แต่ไม่จำเป็นต้องเพิ่มข้อเต็มในใบนี้ทันที งานรอบนี้เพิ่มเฉพาะคำตอบพิมพ์ ยังไม่เปลี่ยนหรือเพิ่มโจทย์เพื่อรักษาขอบเขต 6 ข้อ

ข้อเสนอนี้เป็นการประเมินจากคำถามที่มีอยู่และบันทึกตรวจ สสวท. เดิมใน `BASIC-CALCULATIONS-2026-11-14.md` ไม่ใช่การตรวจข้อสอบ A-Level ชุดใหม่หรือการยืนยันว่าครบแนว A-Level
