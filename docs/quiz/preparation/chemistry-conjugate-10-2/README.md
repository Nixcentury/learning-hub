# ต้นฉบับเคมี 10.2 สำหรับชุดทบทวน

`source-fragments.json` เก็บตัวอย่าง/โจทย์เดิม 21 รายการ และตารางพร้อมคำสั่งเดิม ทั้ง TH/EN จากไฟล์ที่เผยแพร่ในโครงการก่อนปรับ ไม่ใช่ภาพสแกนหนังสือใหม่ มี base commit, blob และ SHA-256 ของ SVG เดิม 8 ภาพ

ต้นฉบับทั้งหมดถูกใช้ในควิซ 50 ข้อแล้ว ดูบัญชีที่ `../../CHEMISTRY-CONJUGATE-10-2-REVIEW.md` ใบเรียนรู้ปัจจุบันใช้ข้อดัดแปลงแทนในตำแหน่งเดิม เก็บสรุปความรู้และจำนวนช่องเดิม พร้อมปรับ Q14 ให้สอดคล้องกับตัวอย่างใหม่

อย่าเพิ่มต้นฉบับกลับเข้าใบเรียนรู้ หรือแก้เครื่องมือกลางเพื่อรองรับโจทย์เฉพาะชุดนี้
