คุณกำลังรับช่วงงานสร้าง Topic Review ของ Learning Hub สำหรับครูศตวรรษ บุตรคล้อ

Repository: Nixcentury/learning-hub
เว็บจริง: https://nixcentury.github.io/learning-hub/
คู่มือหลัก: https://github.com/Nixcentury/learning-hub/blob/main/docs/topic-review/README.md
พรอมป์ต์นี้ใช้ร่วมกับคำสั่งหัวข้อใหม่ที่ผมจะส่งต่อท้าย ไม่ได้ให้สร้างบททวนเรื่องใดเองโดยไม่มีหัวข้อ

เป้าหมายคือเพิ่มบททวนที่ทำงานบนระบบเดิมเหมือนตัวอย่างล่าสุด: ภาษา TH/EN แยกเต็มชุด, เนื้อหาย่อยเป็นช่วง, คำถามเขียนตอบช่วยจำหลังแต่ละช่วง, เว้นพื้นที่หลังทุกข้อย่อย, เฉลยเริ่มซ่อน เปิดรายข้อใหญ่/ทั้งหมด และพิมพ์ A4 ตามภาษากับสถานะเฉลยบนจอ

ก่อนแก้ไฟล์:
1. ใช้ main ล่าสุดของ repo และอ่าน AGENTS.md ที่เกี่ยวข้องถ้ามี
2. อ่าน docs/topic-review/README.md ให้ครบ
3. อ่านไฟล์ตัวอย่าง public/content/reviews/chemistry/periodic-table-main-group.html และ electron-configurations.html
4. อ่านเมนูตัวอย่าง public/content/bank/chemistry/b-5e9670f48386783fee660857.html
5. ตรวจ public/shared/topic-review-model.js, topic-review.js, topic-review.css และ print-core.js เพื่อใช้สัญญาปัจจุบัน
6. หาและยืนยัน subjectId, ชื่อหัวข้อ, บท/path, legacyId และ bankKey จาก catalog จริง ห้ามเดา/hash ID จากชื่อเรื่องหรือใช้ ID ตัวอย่างแทน

แนวการเขียน:
- เป็นใบเรียนรู้ทวนความจำ ไม่ใช่บทความยาวอย่างเดียวหรือ Quiz ใหม่
- แต่ละส่วน: ต้องจำอะไร → สรุป/ภาพ/ตาราง/ตัวอย่าง → คำถามช่วยจำ → ช่องเขียนรายข้อย่อย → เฉลยพร้อมเหตุผล
- เนื้อหาครบแกนของหัวข้อ มีนิยาม สูตร หน่วย เงื่อนไข และข้อยกเว้นสำคัญ แต่เขียนกระชับ
- ใช้ข้อเขียน เติมตาราง วาด หรืออธิบายตามความเหมาะสม ไม่ล็อกจำนวนข้อให้เท่าตัวอย่าง
- TH กับ EN ต้องตรงกันทั้งเลขข้อ ข้อย่อย ตัวเลข สูตร ตาราง เงื่อนไข และคำตอบ
- สร้างแผนภาพแม่นยำด้วย SVG/โค้ดเมื่อช่วยเรียนรู้ ป้ายในภาพ EN และ caption ตามภาษาที่เลือก
- ตรวจข้อเท็จจริงจากแหล่งหลัก ใส่แหล่งศึกษาต่อ เขียนเนื้อหาและคำถามขึ้นใหม่

ขอบเขตงานปกติ:
- public/content/reviews/<subjectId>/<topic-slug>.html
- รูปเฉพาะเรื่องใต้ assets/
- เพิ่มหรืออัปเดต review anchor ใน public/content/bank/<subjectId>/<real-bankKey>.html โดยรักษาเครื่องมืออื่นไว้
- ใช้ templates ใน docs/topic-review/templates/ และเปลี่ยน placeholder ทุกตัว
- ไม่ต้องแก้หรือ Deploy Apps Script เพื่อเพิ่มไฟล์บททวนตามปกติ; ระบบ Review จากคอลัมน์ B เชื่อมแล้ว
- ไม่สร้าง engine, login, CSS global, routes หรือระบบพิมพ์ทดแทนของเดิม และไม่แก้ข้อมูลคะแนน/สมุด/คำตอบเพื่อให้ปุ่มใช้งานได้

สัญญาที่ต้องรักษา:
main[data-topic-review-document]
section[data-content-lang="th"] และ section[data-content-lang="en"]
section[data-review-question] พร้อม h3
ช่องเขียนแต่ละข้อย่อย: data-review-blank + data-review-writing-space
เฉลยหนึ่งกล่องต่อข้อใหญ่: data-review-answer hidden
ไม่เขียนปุ่มเปิด–ปิดหรือ JavaScript เอง และไม่ครอบข้อความโจทย์ใน data-review-blank

การตรวจและส่งงาน:
1. ตรวจทุกคำถามและเฉลยด้วยตนเอง อย่าใช้เพียงผลตรวจโครงสร้างรับรองเนื้อหา
2. รัน node scripts/validate-topic-review.mjs <path>, pnpm test:unit, pnpm build และ git diff --check
3. เปิดผ่าน player จริง ตรวจ TH/EN รูป ข้อความ/พื้นที่เขียน ปุ่มเฉลยรายข้อและทั้งหมด และหน้าจอเล็ก
4. ตรวจการพิมพ์เฉพาะภาษาที่เลือก: ซ่อนทั้งหมด/เปิดบางข้อ/เปิดทั้งหมด โดยคำตอบ Quiz เดิมยังอยู่
5. ทำ branch แยกหัวข้อนี้ ตรวจ main/diff ล่าสุดก่อน merge ไม่ทับงานของอีกบัญชี
6. ใช้สิทธิ์ที่ผมอนุญาตในแชทนี้ดำเนินงานจนเสร็จ หากไม่มีสิทธิ์เขียน/เผยแพร่ ให้ส่งไฟล์หรือ patch ที่พร้อมวางแทนพร้อมรายชื่อพาธ ไม่อ้างว่าเผยแพร่แล้ว
7. แจ้งว่าเสร็จเมื่อ Actions และเว็บจริงตรวจผ่าน มี route ready และไฟล์จริงถูกต้อง ส่งลิงก์ตรงกับสรุปสิ่งที่ทำสั้น ๆ
8. ถ้าจำเป็นต้องถาม ให้ถามเฉพาะข้อมูลที่ยืนยันจาก repo/catalog/เอกสารที่ให้ไม่ได้ และทำส่วนอื่นที่ไม่ติดคำตอบต่อ

หัวข้อ/ระดับชั้น/ประเด็นที่ผมต้องการให้ทำต่อไปจะอยู่ในข้อความถัดจากนี้
