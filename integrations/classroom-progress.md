# ภาพรวมคะแนนส่วนตัวในห้อง Hub

นักเรียนเปิด Classroom → ห้องที่ตนเป็นสมาชิก จะเห็นแผง **ภาพรวมคะแนนของฉัน** ใต้ข้อมูลห้อง มีสองค่าแยกกัน:

- **คะแนนรวมปัจจุบัน** = ผลรวมคะแนนที่ส่งล่าสุดของแต่ละงาน ÷ ผลรวมคะแนนเต็มของ Quiz ใน Hub ทุกงานที่ประกาศ × 100
- **ส่งงานแล้ว** = จำนวนงานที่มีผลส่งล่าสุด ÷ จำนวนงานที่ประกาศทั้งหมด

ตัวอย่าง: มี 3 งาน งานละ 10 คะแนน ได้ 8, 10 และยังไม่ส่ง จะแสดง **18/30 = 60%** และ **ส่งแล้ว 2/3 งาน** งานคะแนนเต็มมากกว่ามีน้ำหนักมากกว่า ไม่ได้เฉลี่ยเปอร์เซ็นต์แต่ละงาน

## งานและคะแนนที่นับ

- รวมงานที่ประกาศแล้วทั้งเปิด ปิด และยังล็อกด้วยเงื่อนไข ไม่นับงานร่าง
- งานยังไม่ส่งมีคะแนน 0 เฉพาะในการคำนวณภาพรวมนี้ ไม่สร้างผลส่ง ไม่เปลี่ยนคะแนนว่างใน CSV และไม่นับว่าทำสำเร็จ
- ใช้เฉพาะผลส่งล่าสุด การฝึกหรือแก้ไขที่ยังไม่กดส่งไม่เปลี่ยนคะแนนรวม การส่งใหม่เปลี่ยนคะแนนรวมได้ทั้งเพิ่มและลด
- ประวัติที่เคยผ่านเกณฑ์มากกว่า 50% ยังใช้ปลดล็อกงานตามเดิม แยกจากคะแนนรวมปัจจุบัน
- งานที่ครูยังไม่เปิดรับการส่งงานยังไม่ทราบคะแนนเต็มจากชุดคำถามที่ตรึงไว้ จึงแสดงสถานะรอโดยไม่สร้างเปอร์เซ็นต์จากข้อมูลบางส่วน
- ระหว่างโหลด หรือเมื่อตรวจคะแนนบางงานไม่ได้ จะไม่แสดงคะแนนรวมเป็น 0 หรือ 100% ที่ชวนให้เข้าใจผิด
- ห้องไม่มีงานแสดงว่าไม่มีงาน ไม่มีเปอร์เซ็นต์ การเชื่อมต่อขาดแสดงคำกำกับข้อมูลล่าสุดที่โหลดได้

แผงนี้ใช้คะแนนเต็มของ Quiz ใน Hub ไม่ได้นำคะแนนเต็ม/น้ำหนักที่ตั้งในชีทหรือ Google Classroom มาคำนวณ การเพิ่มงานใหม่เปลี่ยนคะแนนเต็มรวมและจำนวนงานได้

## สิทธิ์และข้อมูล

อ่านจากข้อมูลผลส่งและชุดคำถามของห้องที่เปิดอยู่เดิม ไม่มี listener หรือการอ่านผลของเพื่อนเพิ่ม นักเรียนเห็นเฉพาะคะแนนตนเอง แผงล้างเมื่อเปลี่ยนบัญชี ออกจากห้อง ถูกนำออก หรือเปลี่ยนสิทธิ์เป็นเจ้าของห้อง ครูเจ้าของห้องยังใช้หน้าดูคะแนนเดิม

ไม่มีการแก้ Firebase Rules ไม่มีการบันทึกเปอร์เซ็นต์รวมกลับฐานข้อมูล ไม่แก้คะแนน/คำตอบ/งาน/CSV และไม่ใช้ Google Classroom API
