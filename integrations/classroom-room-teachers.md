# เพิ่มครูร่วมในห้องด้วยอีเมล

ครูเจ้าของห้องเพิ่มเพื่อนได้เหมือนเพิ่มนักเรียน ผู้รับไม่ต้องเป็นครูที่อนุมัติส่วนกลางก่อน และยังไม่ต้องเคยเข้า Hub

## เปิดใช้ครั้งแรก

เจ้าของ Firebase นำ [Rules ชุดเต็ม classroom-room-teachers.merged-draft.json](../firebase/classroom-room-teachers.merged-draft.json) ไปวางใน Realtime Database → Rules แล้ว Publish ด้วยตนเอง

ชุดนี้ต่อจาก classroom-roster.merged-draft.json บน main 6440e96d2ab4be95f05ef52bc6dce82e99d44f3e รวม Rules ของระบบเดิม ห้อง นักเรียน งาน คะแนน คำตอบ ลิงก์ และติดตามคาบ ไม่ใช่ส่วนย่อยสำหรับลบ Rules เดิมทิ้ง หากเคยเพิ่ม Rules นอก repository ต้องรวมส่วนที่เพิ่มนั้นด้วยก่อน Publish สำรอง Rules ปัจจุบันก่อนเปลี่ยน ไม่มีการเผยแพร่ Rules หรือแก้ฐานข้อมูลจริงอัตโนมัติจาก PR นี้

เมื่อยังไม่ได้วาง Rules ใหม่ ส่วนครูร่วมจะแจ้งว่ายังใช้ไม่ได้ โดยระบบนักเรียนและงานเดิมยังทำงานตาม Rules ที่ใช้อยู่

## เพิ่มครูร่วม

1. เจ้าของห้องเปิด **ห้องเรียน → เปิดห้อง → ครูร่วมในห้อง**
2. กรอก **อีเมลที่เพื่อนใช้เข้าสู่ระบบ Hub** แล้วกด **เพิ่มครูร่วม**
3. กด **แชร์ลิงก์ให้ครูเปิด Classroom** แล้วส่งลิงก์ให้เพื่อนเอง
4. เพื่อนเปิดลิงก์และเข้าสู่ระบบด้วยอีเมลนั้น ห้องที่เชิญจะปรากฏในรายการโดยอัตโนมัติ กด **เปิดห้อง** ได้เลย

ลิงก์เปิดหน้า Classroom โดยไม่แนบอีเมลหรือรหัสลับ การอนุญาตผูกกับอีเมลที่ยืนยันแล้วและ UID ของบัญชีที่รับคำเชิญ ไม่ได้ให้สิทธิ์กับทุกคนที่ได้รับลิงก์ ไม่มีการส่งอีเมลให้อัตโนมัติ

รายการที่ยังไม่รับจะแสดง **รอเข้า Hub** และเจ้าของยกเลิกได้ กดเพิ่มอีเมลเดิมซ้ำไม่สร้างรายการซ้ำ

## สิทธิ์ในห้อง

| การทำงาน | เจ้าของห้อง | ครูร่วม | นักเรียน |
| --- | --- | --- | --- |
| ดูรายชื่อนักเรียน | ได้ | ได้ | ไม่ได้ |
| สร้าง แก้ เผยแพร่ ปิดงาน และดูงานร่าง | ได้ | ได้ | ไม่ได้ |
| เปิดรับงาน ดูคะแนนที่ส่ง และส่งออก CSV | ได้ | ได้ | เฉพาะงาน/คะแนนของตนตามระบบเดิม |
| อ่านและเพิ่มลิงก์ | ได้ | ได้ | ได้ |
| แก้หรือลบลิงก์ของทุกคน | ได้ | ได้ | เฉพาะของตนเอง |
| เพิ่ม/ถอนครูร่วม และจัดการสมาชิกนักเรียน | ได้ | ไม่ได้ | ไม่ได้ |
| ควบคุมการติดตามคาบเรียน | ได้ | ไม่ได้ในรอบนี้ | เข้าร่วมคาบตามระบบเดิม |
| สร้างห้องของตนเอง | ต้องมีสิทธิ์ครูส่วนกลาง | ต้องขอสิทธิ์ครูส่วนกลางเพิ่ม | ไม่ได้ |

ครูร่วมดูคะแนนที่ส่งแล้วได้ แต่เปิดคำตอบฉบับร่างส่วนตัวของนักเรียนหรือเขียนคะแนนปลอมลงผลส่งงานไม่ได้ การสร้างงานยังคง ownerUid ของเจ้าของห้องเดิม ผู้รับไม่กลายเป็นเจ้าของห้องหรือแอดมิน Hub

## ถอนและเพิ่มใหม่

เจ้าของห้องกด **ถอนครูร่วม → ยืนยันถอนครูร่วม** ในส่วนเดียวกัน สิทธิ์จัดการและข้อมูลครูในห้องที่เปิดจะถูกปิดผ่าน listener และ Rules โดยไม่ลบงาน คะแนน คำตอบ หรือลิงก์ที่เคยเพิ่ม

ถ้าบัญชีเคยเป็นนักเรียนห้องนี้ก่อนเพิ่มเป็นครูร่วม การถอนครูร่วมจะคืนสถานะนักเรียนเดิมพร้อมงานและวันที่เข้าห้องเดิม บัญชีที่มีทั้งสองสถานะต้องถอนครูร่วมก่อนนำออกจากสมาชิกนักเรียน เจ้าของเชิญอีเมลเดิมอีกครั้งได้

## ข้อมูลและการทดสอบ

- เพิ่ม classroomV1/teachers, teacherInvitations และค่า teacher ใน userRooms; ไม่เปลี่ยน ownerUid หรือย้ายข้อมูลนักเรียน/คะแนน
- คำเชิญค้นด้วยดัชนี email ของตนหรือ roomId ของเจ้าของ รายชื่อครูร่วมและนักเรียนโหลดเฉพาะห้องที่เปิด ปิด listener เมื่อกลับรายการ สลับห้อง บัญชีเปลี่ยน หรือเสียสิทธิ์
- ใช้ Firebase Realtime Database และแพ็กเกจเดิม ไม่มีบริการส่งเมลหรือระบบ Google Classroom API เพิ่มในงานนี้
- สร้างไฟล์เต็มซ้ำได้ด้วย node scripts/build-classroom-room-teacher-rules.mjs
- ทดสอบ Rules กับ emulator ด้วย pnpm test:classroom:roster; ทดสอบ UI/บริการด้วย pnpm test:unit และ production Hub กับ emulator ใน CI
