# เพิ่มบัญชีครูจาก Classroom

ระบบนี้อนุมัติบัญชีครูของ Learning Hub ให้สร้างและจัดการห้องของตนเอง การเพิ่มครูร่วมในห้องของผู้อื่นและการเชื่อม Google Classroom เป็นคนละงาน

## เปิดใช้ครั้งแรก

เจ้าของโปรเจกต์ Firebase ตั้งแอดมิน Hub คนแรกครั้งเดียว:

1. ให้บัญชีแอดมินเข้าสู่ระบบ Hub แล้วคัดลอก UID จาก Authentication → Users หรือหน้า admin.html
2. ใน Realtime Database → Data เพิ่ม learningHub/admins/UID ของบัญชีนั้น เป็น Boolean true โดยคงข้อมูลเดิม
3. รีเฟรช Hub → ห้องเรียน จะเห็นปุ่ม **เพิ่ม / จัดการครู**

บัญชีที่อนุมัติเป็นครูอย่างเดียวไม่ใช่แอดมิน จึงอนุมัติครูคนอื่นไม่ได้ สิทธิ์จัดการโปรเจกต์ Firebase กับแอดมิน Hub เป็นคนละส่วน งานนี้ใช้ Rules ของ learningHub เดิม ไม่มี Rules ใหม่ให้ Publish

## เพิ่มครูด้วยอีเมล

1. แอดมินเปิด **ห้องเรียน → เพิ่ม / จัดการครู**
2. กรอกอีเมลเต็ม กด **ค้นหาบัญชี** ระบบค้นแบบตรงทั้งอีเมล โดยไม่สนตัวพิมพ์ใหญ่/เล็ก
3. ตรวจชื่อและอีเมล แล้วกด **อนุมัติเป็นครู**
4. ผู้รับใช้บัญชีนั้นเปิดหรือรีเฟรช Hub เพื่อสร้างห้องของตนเอง

ผู้รับต้องเคย **เข้าสู่ระบบ Learning Hub** อย่างน้อยหนึ่งครั้ง การมีชื่อใน Firebase Authentication จากแอปอื่นเพียงอย่างเดียวยังไม่พอ หากไม่พบ ให้ส่งลิงก์ให้เพื่อนเข้า Hub แล้วค้นหาอีกครั้ง หากมีหลาย UID ใช้อีเมลเดียวกัน ระบบจะไม่เลือกให้เอง

คำขอจากเมนูสิทธิ์บัญชีเดิมแสดงในรายการรออนุมัติ รายชื่อครูรองรับทั้งค่า true เดิมและ enabled: true

## แชร์ลิงก์ให้เพื่อน

ครูหรือแอดมินกด **แชร์ลิงก์ให้ครู** บนหน้า Classroom ได้ หน้าจอจัดการครูก็มี **คัดลอกลิงก์ให้เพื่อน** และช่องลิงก์สำหรับคัดลอกเองเมื่อเบราว์เซอร์ไม่อนุญาตให้คัดลอกอัตโนมัติ

ลิงก์ไป #classroom เท่านั้น ไม่แนบอีเมล โทเคน รหัสห้อง คะแนน หรือคำตอบ และไม่ให้สิทธิ์ครูด้วยตัวลิงก์ ผู้ใช้คัดลอกส่งให้เพื่อนเอง ไม่มีการส่งอีเมลอัตโนมัติ

## ถอนสิทธิ์และข้อมูลเดิม

แอดมินเลือก **ถอนสิทธิ์ครู** ตรวจบัญชีในข้อความยืนยัน แล้วกด **ยืนยันถอนสิทธิ์** การถอนสิทธิ์ไม่ลบห้อง คะแนน คำตอบ หรืองานเดิม บัญชีที่ถูกถอนจะใช้เครื่องมือครูไม่ได้ตาม Rules เดิม

บัญชีแอดมินยังมีสิทธิ์ครูจากเครื่องหมาย admins หน้านี้ไม่จัดการเครื่องหมาย admins และไม่ให้ถอนบัญชีที่กำลังใช้งาน

รายชื่อโหลดเฉพาะตอนแอดมินเปิดหน้าต่าง ปิดแล้วเลิกฟัง รวมถึงเมื่อออกจาก Classroom สลับบัญชี หรือสิทธิ์เปลี่ยน ข้อมูลไดเรกทอรีอยู่ในหน้าหลัก ไม่ส่งบัญชีทั้งหมดเข้า iframe ของ Classroom
