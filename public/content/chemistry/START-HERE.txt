เริ่มเชื่อมบทตัวอย่างเมื่อพร้อม
==============================
1. สร้าง public/content/chemistry/equilibrium.html โดยใส่เนื้อหานี้:

<nav data-learning-menu data-menu-kind="topics"
  data-subject-id="chemistry" data-chapter-id="9"
  data-title-th="บทที่ 9 สมดุลเคมี" data-title-en="Chapter 9 Chemical Equilibrium"
  data-description-th="เลือกเรื่องย่อย" data-description-en="Choose a topic">
  <a data-topic-id="le-chatelier" href="equilibrium/le-chatelier.html"
    data-th="หลักของเลอชาเตอลิเย" data-en="Le Chatelier's principle">หลักของเลอชาเตอลิเย</a>
</nav>

2. ใน public/pages/chemistry.html หาแท็กเปิด <article data-chapter="9">
   เพิ่มเฉพาะ data-chapter-src โดยคงชื่อบทและคำอธิบายเดิมด้านในไว้:

   <article data-chapter="9" data-chapter-src="../content/chemistry/equilibrium.html">

3. ตรวจเนื้อหาและ Build ตามท้ายคู่มือ แล้ว Commit/Push ก่อนลองบนเว็บจริง
   ถ้าแค่วางไฟล์ไว้โดยไม่เชื่อมเมนู ไฟล์จะมี URL แต่ไม่มีรายการนำทางไปหาเอง

หน้าตาการ์ด ปุ่ม ภาษา และการเปิดงานมาจากระบบกลาง
ไฟล์ HTML เมนูไม่ต้องใส่ CSS, JavaScript หรือสร้างปุ่มเอง
ไม่ต้องเพิ่มรายการซ้ำใน js/workspace.js หรือแก้ Quiz Engine
บทอื่นที่ยังไม่ได้ใส่ data-chapter-src ยังคงใช้ทางเปิดแบบเดิม

งานที่ทำบ่อยที่สุด: เพิ่ม Quiz อีกชุดในเรื่องเดิม
===============================================
1. คัดลอก equilibrium/quiz-template.html เป็น equilibrium/practice-02.html
2. เปิดไฟล์ใหม่แล้วเปลี่ยน data-activity-id เป็นรหัสใหม่ เช่น chem-le-chatelier-practice-02
3. เปลี่ยนชื่อ สรุป โจทย์ ตัวเลือก คำใบ้ และเฉลย
   รหัสข้อ data-question-id ต้องไม่ซ้ำภายในชุด
   ชุดเดียวรวมข้อกาและข้อเติมตัวเลขได้ ส่วนลากวางต้องเป็นชุดแยก
4. เปิด equilibrium/le-chatelier.html
5. คัดลอก <a ...>...</a> เดิมทั้งรายการ วางเพิ่มก่อน </nav> แล้วแก้ให้เป็น:

  <a data-tool-kind="quiz" data-content-id="chem-le-chatelier-practice-02"
    href="practice-02.html"
    data-th="เลอชาเตอลิเย ชุดที่ 2" data-en="Le Chatelier Set 2"
    data-description-th="แบบฝึกหัดเพิ่มเติม" data-description-en="More practice">เลอชาเตอลิเย ชุดที่ 2</a>

สำคัญ: data-content-id ในเมนูต้องตรงกับ data-activity-id ในไฟล์ Quiz ใหม่
href คือที่อยู่ไฟล์จากตำแหน่ง HTML เมนูที่กำลังแก้ ไม่ใช่จากหน้า Hub
ตัวอย่าง practice-02.html ยังไม่ได้สร้าง เป็นตัวอย่างขั้นตอนให้คัดลอกเอง

เพิ่มเรื่องย่อยในบทเดิม
======================
ถ้ายังไม่พร้อมทำเนื้อหา: เพิ่มชื่อเรื่องใน HTML บทโดยไม่ใส่ href ได้เลย เช่น

  <a data-topic-id="new-topic" data-th="เรื่องใหม่" data-en="New topic">เรื่องใหม่</a>

ระบบจะแสดงชื่อพร้อม "กำลังเตรียมเนื้อหา" บนการ์ด และยังไม่เปิดให้กด
ไม่ต้องสร้างไฟล์ปลายทางจนกว่าจะพร้อม เมื่อพร้อมค่อยเพิ่ม href ที่ถูกต้อง
href ที่ใส่แล้วต้องชี้ไฟล์จริงเสมอ หากพิมพ์ผิดตัวตรวจยังแจ้งเตือนตามเดิม
วิธีนี้ใช้กับหัวข้อชั้น 2 ส่วนรายการ Quiz/เครื่องมือชั้น 3 ยังต้องมีปลายทาง

1. คัดลอก equilibrium/le-chatelier.html เป็น equilibrium/equilibrium-constant.html
2. เปลี่ยน data-topic-id ที่ <nav> เป็น equilibrium-constant
3. เปลี่ยน data-title-th/data-title-en และคำอธิบายของเรื่อง
4. แก้รายการงานด้านในให้ชี้ไฟล์ที่ต้องการ หรือเอา <a> ออกทั้งหมดเพื่อเตรียมเรื่องเปล่า
5. เปิด equilibrium.html แล้วคัดลอก <a> เพิ่มหนึ่งรายการ เช่น:

  <a data-topic-id="equilibrium-constant" href="equilibrium/equilibrium-constant.html"
    data-th="ค่าคงที่สมดุล" data-en="Equilibrium constants"
    data-description-th="นิพจน์และการคำนวณ" data-description-en="Expressions and calculations">ค่าคงที่สมดุล</a>

data-topic-id ของรายการและ <nav> ในไฟล์เรื่องย่อยต้องตรงกัน
เรื่องที่ไม่มีรายการงานจะแสดงว่ากำลังเตรียมเนื้อหา

เพิ่มให้บทอื่นที่มีชื่ออยู่แล้ว
==============================
1. คัดลอก equilibrium.html และแฟ้ม equilibrium/ เป็นชื่อบทใหม่
2. แก้ชื่อบทและ data-chapter-id ใน HTML เมนูทั้งหน้าบทและหน้าเรื่องย่อย
3. แก้ href ให้ตรงกับชื่อแฟ้ม/ไฟล์ใหม่
4. ถ้าสร้าง Quiz ชุดใหม่ ให้เปลี่ยนรหัสชุดในเนื้อหาและในเมนูให้ตรงกัน
5. เปิด HTML รายวิชา หา <article data-chapter="เลขบทเดิม">
   แล้วเพิ่ม data-chapter-src ชี้ไปไฟล์เมนูบท เช่นบท 9 ที่ทำไว้:

  <article data-chapter="9" data-chapter-src="../content/chemistry/equilibrium.html">

อย่าเปลี่ยนเลขบทเดิมเพียงเพื่อให้ตรงกับเลขที่คัดลอกมา
ถ้าเพิ่มในวิชาอื่น ให้ใช้แฟ้มวิชานั้นและแก้ data-subject-id ในเมนูให้ตรงกับหน้าวิชา
ตัวอย่างชื่อวิชาที่ระบบใช้: physics, chemistry, biology
สำหรับบทที่มี data-chapter-src ระบบอ่านจำนวนรายการจาก HTML ไม่ต้องเพิ่มจำนวนบทใน JavaScript

เรื่องหนึ่งมีหลายงาน / งานเดียวอยู่หลายเรื่อง
============================================
เพิ่ม <a> ได้หลายรายการในเมนูเรื่องย่อย ทุกใบเปิดงานได้ตรงจากชั้น 3
ถ้างานเดิมต้องปรากฏอีกเรื่อง ให้ลิงก์ไปไฟล์เดิมและใช้รหัสชุดเดิม
ไม่ต้องคัดลอกไฟล์เป็น Quiz ใหม่เพียงเพราะต้องการแสดงหลายที่
ถ้าคัดลอกไปสร้างโจทย์อีกชุดจริง ๆ ต้องตั้งรหัสชุดใหม่เพื่อแยกคำตอบและสมุด
เมื่อแก้ชื่อหรือย้ายหมวดของชุดเดิม อย่าเปลี่ยนรหัสชุดและรหัสข้อ
หลีกเลี่ยงย้าย/เปลี่ยนชื่อไฟล์ที่แจก URL ไปแล้ว เพราะลิงก์เก่าจะขาด

Simulation (ตัวเลือก ไม่ได้สร้างตัวอย่าง Simulation ใหม่ในรอบนี้)
================================================================
เมนูใช้ data-tool-kind="simulation" และ href ชี้ HTML ของ Simulation
ไฟล์ Simulation เป็น HTML เต็มได้ โดยระบุที่แท็ก <html>:
  data-learning-simulation data-activity-id="รหัสเดียวกับเมนู"
การเปิด Simulation ไม่ได้ทำให้เซฟคะแนน/ขั้นตอนใน Firebase อัตโนมัติ
ส่วนการเชื่อมคะแนนของ Simulation เป็นอีกเรื่องหนึ่ง ไม่รวมใน Navigation รอบนี้
