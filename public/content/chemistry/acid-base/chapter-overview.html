บทที่ 10 กรด-เบส (Acids and Bases)

เคมี ม.5 เล่ม 4 ตามหลักสูตรแกนกลางการศึกษาขั้นพื้นฐาน (สสวท. ฉบับปรับปรุง พ.ศ. 2560)

ผลการเรียนรู้ที่คาดหวัง (Learning Outcomes)

  1. ระบุและอธิบายว่าสารเป็นกรดหรือเบส โดยใช้ทฤษฎีกรด-เบสของอาร์เรเนียส เบรินสเตด-ลาวรี และลิวอิส
  2. ระบุคู่กรด-เบสของสาร ตามทฤษฎีกรด-เบสของเบรินสเตด-ลาวรี
  3. คำนวณและเปรียบเทียบความสามารถในการแตกตัวหรือความแรงของกรดและเบส
  4. คำนวณค่า pH ความเข้มข้นของไฮโดรเนียมไอออนหรือไฮดรอกไซด์ไอออนของสารละลายกรดและเบส
  5. เขียนสมการเคมีแสดงปฏิกิริยาสะเทิน และระบุความเป็นกรด-เบสของสารละลายหลังการสะเทิน
  6. เขียนปฏิกิริยาไฮโดรไลซิสของเกลือ และระบุความเป็นกรด-เบสของสารละลายเกลือ
  7. ทดลองและอธิบายหลักการการไทเทรต และเลือกใช้อินดิเคเตอร์ที่เหมาะสมสำหรับการไทเทรตกรด-เบส
  8. คำนวณปริมาณสารหรือความเข้มข้นของสารละลายกรดหรือเบสจากการไทเทรต
  9. อธิบายสมบัติ องค์ประกอบ และประโยชน์ของสารละลายบัฟเฟอร์
  10. สืบค้นข้อมูลและนำเสนอตัวอย่างการใช้ประโยชน์และการแก้ปัญหาโดยใช้ความรู้เกี่ยวกับกรด-เบส

สาระสำคัญและหลักการคำนวณ (Key Concepts & Calculations)

1. ทฤษฎีกรด-เบส และคู่กรด-เบส

  • อาร์เรเนียส (Arrhenius): กรดละลายน้ำแตกตัวให้ H+ (หรือ H3O+) และเบสแตกตัวให้ OH- (จำกัดเฉพาะในน้ำ)
  • เบรินสเตด-ลาวรี (Brønsted-Lowry): กรดคือตัวให้โปรตอน (H+ donor) ส่วนเบสคือตัวรับโปรตอน (H+ acceptor)
  • ลิวอิส (Lewis): กรดคือตัวรับคู่อิเล็กตรอน (Electron pair acceptor) ส่วนเบสคือตัวให้คู่อิเล็กตรอน (Electron pair donor)
  • คู่กรด-เบส (Conjugate pair): มีสูตรต่างกันเพียง H+ 1 ตัว โดยคู่กรดจะมี H มากกว่าคู่เบส 1 ตัวเสมอ เช่น H2O (คู่เบส) / H3O+ (คู่กรด) หรือ NH4+ (คู่กรด) / NH3 (คู่เบส)

2. การแตกตัวของกรด-เบส และการคำนวณด้วยตาราง ICE

  • กรดแก่และเบสแก่: แตกตัวได้ 100% คิดความเข้มข้นไอออนจากอัตราส่วนโมลของสมการเคมีได้โดยตรง
  • กรดอ่อนและเบสอ่อน: แตกตัวบางส่วนเกิดสมดุลเคมี ไม่ใช้สูตรลัดแต่ต้องคำนวณตามขั้นตอนสมดุล (ตาราง ICE):
ตัวอย่างการคำนวณกรดอ่อน HA ความเข้มข้นเริ่มต้น C mol/L (ค่าคงที่ Ka):
สมการสมดุล: HA(aq) + H2O(l) ⇌ H3O+(aq) + A-(aq)
สภาวะ [HA] (mol/L) [H3O+] (mol/L) [A-] (mol/L)
I (เริ่มต้น) C 0 0
C (เปลี่ยนไป) -x +x +x
E (ที่สมดุล) C - x x x
แทนค่าในนิพจน์ค่าคงที่สมดุล:
Ka = ([H3O+][A-]) / [HA] = (x · x) / (C - x) = x2 / (C - x)
จัดรูปสมการกำลังสองจริง: x2 + Kax - KaC = 0
แก้สมการหาค่า x ด้วยสูตรพหุนาม: x = [-Ka + √(Ka2 + 4KaC)] / 2
เมื่อได้ x จะได้ [H3O+] = x mol/L และหาร้อยละการแตกตัวได้จาก: % การแตกตัว = (x / C) × 100

3. สมดุลการแตกตัวของน้ำ ค่า pH และ pOH

  • น้ำแตกตัวได้เอง: 2H2O(l) ⇌ H3O+(aq) + OH-(aq)
  • ค่าคงที่การแตกตัวของน้ำ: Kw = [H3O+][OH-] = 1.0 × 10-14 (ที่ 25 °C)
  • สำหรับคู่กรด-เบสใด ๆ ในน้ำ: Ka × Kb = Kw
  • การคำนวณเชิงลอการิทึม:
    • pH = -log[H3O+] และ [H3O+] = 10-pH
    • pOH = -log[OH-] และ [OH-] = 10-pOH
    • pH + pOH = 14.00 (ที่ 25 °C)

4. ปฏิกิริยาสะเทินและการคำนวณไทเทรต (วิธีเทียบโมลตามสมการดุล)

  • ปฏิกิริยาสะเทิน (Neutralization): กรด + เบส → เกลือ + น้ำ
  • จุดสมมูล (Equivalence Point): ปริมาณกรดและเบสทำปฏิกิริยากันพอดีตามปริมาณสารสัมพันธ์
  • จุดยุติ (End Point): จุดที่อินดิเคเตอร์เปลี่ยนสี ต้องเลือกใช้อินดิเคเตอร์ที่ช่วงการเปลี่ยนสีครอบคลุมค่า pH ณ จุดสมมูล
การคำนวณการไทเทรตโดยใช้ปริมาณสารสัมพันธ์ (ไม่ใช้สูตรลัด):
1. เขียนและดุลสมการเคมี: a กรด + b เบส → เกลือ + น้ำ
2. เทียบอัตราส่วนโมลที่ทำปฏิกิริยาพอดี: (โมลของกรด) / a = (โมลของเบส) / b
3. กระจายโมลจากความเข้มข้นและปริมาตร: (Cกรด × Vกรด / 1000) / a = (Cเบส × Vเบส / 1000) / b
(ตัด 1000 ทั้งสองข้าง จะได้ความสัมพันธ์ที่ถูกต้องตามสัมประสิทธิ์สมการเคมีเสมอ)

5. ปฏิกิริยาไฮโดรไลซิสของเกลือ (Salt Hydrolysis)

ไอออนที่มาจากสารอ่อนเท่านั้นที่จะทำปฏิกิริยากับน้ำ ส่งผลต่อ pH ของสารละลาย:

  • กรดแก่ + เบสแก่ (เช่น NaCl): ทั้ง Na+ และ Cl- ไม่ทำปฏิกิริยากับน้ำ → สารละลายเป็นกลาง (pH = 7)
  • กรดแก่ + เบสอ่อน (เช่น NH4Cl): ไอออน NH4+ ไฮโดรไลซิสได้ H3O+:
    NH4+(aq) + H2O(l) ⇌ NH3(aq) + H3O+(aq) → สารละลายเป็นกรด (pH < 7)
  • กรดอ่อน + เบสแก่ (เช่น CH3COONa): ไอออน CH3COO- ไฮโดรไลซิสได้ OH-:
    CH3COO-(aq) + H2O(l) ⇌ CH3COOH(aq) + OH-(aq) → สารละลายเป็นเบส (pH > 7)
  • กรดอ่อน + เบสอ่อน (เช่น NH4CN): เกิดไฮโดรไลซิสทั้งสองไอออน ตัดสินความเป็นกรด-เบสโดยเปรียบเทียบค่า Ka และ Kb

6. สารละลายบัฟเฟอร์ (Buffer Solutions)

  • สารละลายที่รักษาระดับ pH ให้คงที่เมื่อเติมกรดแก่หรือเบสแก่ลงไปเล็กน้อย
  • องค์ประกอบ: กรดอ่อน + เกลือของกรดอ่อน (คู่เบส) หรือ เบสอ่อน + เกลือของเบสอ่อน (คู่กรด)
  • การคำนวณสมดุลบัฟเฟอร์ด้วยตาราง ICE:
    ตั้งสมดุล HA ⇌ H3O+ + A- โดยในตอนเริ่มต้น (I) มีทั้ง [HA] = Ca และ [A-] = Cs
    แทนค่าในนิพจน์สมดุล: Ka = [H3O+](Cs + x) / (Ca - x)
    (เมื่อ x แตกตัวน้อยมากเมื่อเทียบกับความเข้มข้นสารเริ่มต้น จะได้ [H3O+] = Ka · (Ca / Cs))
  • การประยุกต์ใช้: ควบคุมสมดุลกรด-เบสในเลือดมนุษย์ผ่านระบบบัฟเฟอร์ H2CO3 / HCO3- เพื่อคงค่า pH ให้อยู่ระหว่าง 7.35–7.45
