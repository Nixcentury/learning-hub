1. ธาตุเดียวกัน ทำไมบางไอโซโทปสลายตัว

ในแบบจำลองเริ่มต้นมี Na-24 ทั้งหมด เมื่อเวลาผ่านไป Na-24 เหลือครึ่งหนึ่ง นิวเคลียสส่วนที่สลายไปกลายเป็นอะไร?

สังเกตที่ 0 และ 15 ชั่วโมง นิวเคลียสชนิดใดลดลง และชนิดใดเพิ่มขึ้น?

อ่านสัญลักษณ์นิวเคลียร์

AZX โดย X คือสัญลักษณ์ธาตุ Z คือจำนวนโปรตอน A คือจำนวนโปรตอนรวมกับนิวตรอน และ N คือจำนวนนิวตรอน

N = A − Z(1)

นิวเคลียสที่ไม่เสถียรอาจสลายได้เองพร้อมปล่อยอนุภาคหรือรังสี เรียกว่า กัมมันตภาพรังสี ความเสถียรขึ้นกับองค์ประกอบของนิวเคลียส รวมถึงสัดส่วนนิวตรอนต่อโปรตอน

3. ดุลสมการและตามหานิวเคลียสลูก

เลขบน A ใช้นับนิวคลีออน สำหรับนิวเคลียส เลขล่าง Z คือจำนวนโปรตอน ส่วนเลขล่างของอนุภาคที่ปล่อย เช่น −1 ของอิเล็กตรอน คือค่าประจุในหน่วย e สัญลักษณ์ ∑ หมายถึงผลรวมของทุกพจน์

∑ Aleft = ∑ Aright(2)
∑ Zleft = ∑ Zright(3)
สิ่งที่ปล่อยเลขของนิวเคลียสลูกเหตุผล
αA − 4, Z − 2เสียโปรตอน 2 และนิวตรอน 2
β⁻A, Z + 1นิวตรอนหนึ่งตัวเปลี่ยนเป็นโปรตอน
β⁺A, Z − 1โปรตอนหนึ่งตัวเปลี่ยนเป็นนิวตรอน
γA, Zนิวเคลียสลดระดับพลังงาน

ในโจทย์ดุลระดับนี้เขียนบีตาแบบย่อได้ นิวทริโนหรือแอนตินิวทริโนในสมการเต็มมี A = 0 และประจุเป็นศูนย์ จึงไม่เปลี่ยนการดุลเลขทั้งสอง

เมื่อ 2411Na เปลี่ยนเป็น 2412Mg เลขบนและเลขล่างที่เหลือเป็นเท่าไร ตรงกับอนุภาคใด?

ถ้ามีอนุภาคเข้าทำปฏิกิริยาทางซ้าย เช่น นิวตรอน ให้รวมเลขบนและล่างของอนุภาคนั้นด้วย แล้วดุลด้วยหลักเดิม

4. อ่านการลดลงทีละครึ่งก่อนสร้างสูตร

ชี้ที่ 1, 2 และ 3 ครึ่งชีวิต ค่าบนกราฟคือส่วนที่เหลือเท่าไร? หลัง 3 ครึ่งชีวิต สลายไปเท่าไร?

ครึ่งชีวิต คือเวลาที่จำนวนนิวเคลียสของไอโซโทปเดิมที่ยังไม่สลายลดลงเหลือครึ่งหนึ่ง การสลายของนิวเคลียสเดี่ยวเกิดแบบสุ่ม ครึ่งชีวิตอธิบายภาพรวมของนิวเคลียสจำนวนมาก

ให้ t เป็นเวลาที่ผ่านไป T½ เป็นครึ่งชีวิตในหน่วยเดียวกัน และ n เป็นจำนวนช่วงครึ่งชีวิต

n = t/T½(4)

มวลไอโซโทปเดิมลดแบบคูณ ½ ซ้ำทุกช่วง ให้ m0 เป็นมวลตั้งต้น mt เป็นมวลที่ยังไม่สลาย และ f เป็นสัดส่วนที่เหลือ จึงได้

f = mt/m0 = (½)n(5)

ให้ mdecay เป็นมวลของไอโซโทปเดิมส่วนที่สลายไป

mdecay = m0 − mt(6)
