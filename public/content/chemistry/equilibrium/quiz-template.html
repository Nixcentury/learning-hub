10. Le Châtelier's principle / หลักเลอชาเตอลิเยร์ (Q21)

Meaning / ความหมาย: when an equilibrium system is disturbed, it shifts in the direction that partially opposes the disturbance. / เมื่อรบกวนสมดุล ระบบจะเลื่อนไปในทิศที่ช่วยลดผลของการรบกวนบางส่วน

Disturbance / การรบกวนTypical response / การตอบสนอง
add reactant / เพิ่มสารตั้งต้นshift toward products / ไปทางผลิตภัณฑ์
remove reactant / ลดสารตั้งต้นshift toward reactants / ไปทางสารตั้งต้น
add product / เพิ่มผลิตภัณฑ์shift toward reactants / ไปทางสารตั้งต้น
remove product / ลดผลิตภัณฑ์shift toward products / ไปทางผลิตภัณฑ์

Q21 method: identify what was removed or added → identify whether it is a reactant or product → choose the direction that replaces removed material or consumes added material. / ดูว่าเติมหรือนำสารใดออก → ดูว่าเป็น reactant หรือ product → เลือกทิศที่ช่วยสร้างสารที่ถูกนำออกหรือใช้สารที่เติม

Constant-temperature note / หมายเหตุ: concentration changes shift the equilibrium position but do not change the numerical value of Kc at the same temperature. / ที่อุณหภูมิคงที่ การเปลี่ยน concentration ทำให้ตำแหน่งสมดุลเปลี่ยน แต่ค่า Kc ไม่เปลี่ยน
สำหรับสมดุล \(\mathrm{H_2(g)+Br_2(g)\rightleftharpoons2HBr(g)}\) นำ HBr บางส่วนออกโดยคงอุณหภูมิไว้ สมดุลจะเลื่อนไปทางใด?
For the equilibrium \(\mathrm{H_2(g)+Br_2(g)\rightleftharpoons2HBr(g)}\), some HBr is removed while temperature is kept constant. In which direction will the equilibrium shift?
\(\mathrm{H_2(g)+Br_2(g)\rightleftharpoons2HBr(g)}\)
At equilibrium: \([H_2]=0.20\,M,\ [Br_2]=0.20\,M,\ [HBr]=0.60\,M\)
  1. To the right, to form more HBr. / ไปทางขวา เพื่อสร้าง HBr เพิ่ม
  2. To the left, to form more H₂ and Br₂. / ไปทางซ้าย เพื่อสร้าง H₂ และ Br₂ เพิ่ม
  3. No shift / ไม่เลื่อน
  4. Both directions with no net response / ทั้งสองทิศพร้อมกันโดยไม่มีผลสุทธิ
  5. Left because product decreased / ไปทางซ้ายเพราะผลิตภัณฑ์ลดลง
  6. Upward / ทิศขึ้น
  7. Cannot determine even with the equation / สรุปไม่ได้แม้ทราบสมการ
  1. HBr is a product.
    HBr เป็นผลิตภัณฑ์
  2. Removing product disturbs the system.
    การนำผลิตภัณฑ์ออกเป็นการรบกวนระบบ
  3. The system shifts in the direction that helps replace some product.
    ระบบจะเลื่อนไปในทิศที่ช่วยสร้างผลิตภัณฑ์กลับคืนบางส่วน
เมื่อนำ HBr ออก ความเข้มข้นผลิตภัณฑ์ลดลง ตามหลักเลอชาเตอลิเยร์ ระบบตอบสนองโดยเลื่อนไปทางขวาเพื่อสร้าง HBr เพิ่มบางส่วน
ตอบ: เลื่อนไปทางขวา
Removing HBr lowers product concentration. By Le Châtelier's principle, the system shifts right to replace some of the removed HBr.
Answer: shifts to the right.
