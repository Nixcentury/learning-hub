# Physics 10.1 visual assets

The 14 original SVG diagrams have explained and student variants. Student files physically omit answer graphics and solution metadata. They are authored content, not a new rendering or language engine. Circular-interference loci use exact path differences; the diffraction wavefronts use a scalar angular-spectrum model for review. No slit-fringe calculation is introduced in this sheet.
