ก่อนเริ่ม:
อ่าน START-HERE.txt, QUESTION-BANK-START-HERE.md,
public/content/templates/bank-id-authoring-guide.txt, เมนูจริง และคู่มือชนิดสื่อ
ตรวจว่า branch นี้เชื่อมตัวอ่าน HTML bank แล้ว หากยังไม่มีให้หยุดแจ้งผู้ใช้
ถ้าอ่าน repo/ไฟล์ไม่ได้ ให้บอกตามจริงและขอแนบไฟล์ ไม่เดาโครงสร้าง

วิธีทำ:
1. ตรวจแหล่งและเสนอขอบเขตหัวข้อตาม สสวท. ก่อน ไม่แต่งว่าอ่านหนังสือครบแล้ว
2. สร้างสื่อเป็นไฟล์ใน public/content/<วิชา>/ ใช้แม่แบบจริง
3. เพิ่ม a ในเมนูเท่าที่พร้อม ไม่ต้องแก้ JavaScript หรือ generated catalog
4. ทุกสื่อมีชื่อ TH/EN และ ID คงที่; สื่อร่วมใช้ไฟล์และ ID เดิม
5. Open quiz/Notebook ระบบใส่เอง ห้ามใช้ tool-key quiz/notebook หรือแทน Quiz คลัง
6. PDF เติม data-pdf-common, data-pdf-th, data-pdf-en ติดกัน ช่องว่างได้
7. ไม่พร้อมให้เว้น href หรือ data-status="draft" ไม่แต่ง URL และไม่แต่งข้อสอบจำลอง
8. ถ้าแก้ slug ที่มีผู้ใช้แล้ว ต้องเก็บ slug เก่าใน data-route-aliases
9. ไม่เปลี่ยน bankKey/legacyId/contentId/questionId/revision เดิม ไม่แก้คะแนน/เซฟ
10. ตรวจตามคู่มือ รายงานสิ่งที่รันได้จริง แยก commit/build/deploy/เว็บจริง

ส่งกลับ:
- ขอบเขตและแหล่งอ้างอิง พร้อมสิ่งที่ยังตรวจไม่ได้
- รายชื่อไฟล์และรายการเมนูที่เปลี่ยน
- ID คงเดิม/ID ใหม่ และเหตุผล
- ผลทดสอบจริงและสิ่งที่ยังต้องทดสอบ
- ลิงก์หน้าเป้าหมายหลังยืนยันเผยแพร่แล้วเท่านั้น

ถ้าไม่มีสิทธิ์ push หรือไม่มี runtime ให้ส่งไฟล์/branch งานกับคำสั่งตรวจต่อ
ห้ามอ้างว่าเว็บอัปเดตแล้วเพียงเพราะสร้างไฟล์เสร็จ
