สร้าง HTML สรุปบทสำหรับหน้าต่างอ่านกลางของ Learning Hub
ฉันจะระบุวิชา ชื่อบท ผลการเรียนรู้ และเนื้อหาให้ท้ายคำสั่งนี้

ข้อกำหนดที่ต้องทำตาม
1. ส่ง HTML สมบูรณ์หนึ่งไฟล์ เริ่ม <!doctype html> และใช้ <html lang="th" data-learning-html>
2. แยกส่วนผลการเรียนรู้กับสาระสำคัญ รักษาข้อมูลและภาษาตามที่ฉันให้ ห้ามอ้างว่าตรงหลักสูตรหากยังไม่ได้ตรวจแหล่งข้อมูล
3. ใส่ CSS ใน <style> ได้ ให้อ่านง่ายบนมือถือ/iPad รูปภาพไม่ล้นจอ ตารางกว้างให้อยู่ในกล่อง overflow-x:auto
4. ห้ามใส่ <script>, onclick หรือ event handler ใด ๆ, iframe, form, object, embed และห้ามลิงก์ javascript:
5. ไม่ต้องโหลด MathJax หรือ CDN เอง ไม่ต้องมีปุ่มพิมพ์/PDF ปุ่มบันทึก ล็อกอิน AI หรือตัวควบคุมหน้าต่าง ระบบกลางดูแลเอง (งานพิมพ์ยังเป็นเฟสถัดไป)
6. สมการในบรรทัดใช้ \(...\) สมการแยกบรรทัดใช้ \[...\] ห้ามใช้ $...$ สำหรับสูตรในบรรทัด
7. ใช้ LaTeX สำหรับเศษส่วน ราก เลขยกกำลัง log sin เวกเตอร์ ตัวแปรกรีก อินทิกรัล และผลรวม เช่น \(\frac{1}{2}\), \(\sqrt{x}\), \(\vec{F}\), \(\alpha\)
8. สูตรเคมีใช้ mhchem ภายในตัวคั่นสมการ เช่น \(\ce{H3O+}\), \(\ce{SO4^2-}\)
   สมการตัวอย่าง: \[\ce{HA(aq) + H2O(l) <=> H3O+(aq) + A-(aq)}\]
   ลูกศร <=> ในไฟล์ HTML เขียนเป็น &lt;=&gt; ได้ โดยอ่านกลับเป็น <=> เหมือนเดิม
9. สูตรทั้งชุดภายในตัวคั่นต้องเป็นข้อความเดียว ห้ามแทรก <sub>, <sup>, <br>, <span> หรือแท็ก HTML ลงในสูตร
   ใช้ _ และ ^ สำหรับตัวห้อย/ยกกำลัง ใช้ \frac{}{} กับ \sqrt{} ใช้ \begin{aligned}...\end{aligned} สำหรับหลายบรรทัด
10. ไม่ใช้ \require, \href, \style, \class, \htmlClass, \def หรือ \newcommand ไม่โหลดแพ็กเกจเอง ระบบรองรับ base, ams และ mhchem
11. ใช้ข้อความไทยเป็น HTML นอกสูตร ใช้ \mathrm{} หรือ \text{} สำหรับคำอังกฤษ/หน่วยในสูตร
12. หากต้องแสดงตัวอย่างโค้ด LaTeX โดยไม่จัดรูป ให้ใส่ใน <pre><code> หรือครอบด้วย data-no-math
13. รักษาความถูกต้องทางวิชาการ ไม่เปลี่ยนสมการหรือเติมสมมติฐานเองเพียงเพื่อให้แสดงสวย
14. สมการจะจัดรูปเมื่อเปิดผ่าน Hub เท่านั้น เปิด HTML เดี่ยวจากเครื่องจะแสดงข้อความ LaTeX ต้นฉบับ ห้ามแก้ด้วยการใส่สคริปต์

ตัวอย่างโครง:
<!doctype html>
<html lang="th" data-learning-html>
<head><meta charset="utf-8"><meta name="viewport" content="width=device-width, initial-scale=1"><title>ชื่อบท</title></head>
<body><main>
  <h1>ชื่อบท</h1>
  <section><h2>ผลการเรียนรู้ที่คาดหวัง</h2><ol><li>...</li></ol></section>
  <section><h2>สาระสำคัญ</h2>
    <p>ค่าคงที่ \(K_a\)</p>
    \[K_a=\frac{x^2}{C-x}\]
    \[x=\frac{-K_a+\sqrt{K_a^2+4K_a C}}{2}\]
  </section>
</main></body></html>
