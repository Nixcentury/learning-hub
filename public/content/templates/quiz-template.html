Which part keeps the buttons, notebook, AI review, and PDF export consistent across every quiz?
  1. A. ไฟล์เนื้อหาแต่ละชุด / Each content file

  4. D. ชื่อแท็บวิชา / The subject-tab name
  1. มองหาส่วนที่ทุก Quiz เรียกใช้ร่วมกัน
    Look for the component shared by every quiz.
  2. ไฟล์เนื้อหาไม่ควรสร้างเครื่องมือซ้ำเอง
    A content file should not recreate the tools.
ตอบ B — Quiz Engine กลางเป็นผู้สร้างหน้าตา ปุ่ม สมุดทด AI และ PDF ให้ทุกชุด

  1. A. สรุป โจทย์ ตัวเลือก คำใบ้ และเฉลย / Summary, questions, choices, hints, and solutions

    The shared tools already exist, so only content should change.
  2. ห้ามสร้าง Engine หรือ workflow ใหม่ในไฟล์ Quiz
    Do not create a new engine or workflow inside a quiz file.
