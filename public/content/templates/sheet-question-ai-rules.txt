LEARNING HUB — กติกาสำหรับ AI สร้างข้อสอบใน Google Sheet
ฉบับ 26 ตุลาคม 2026 · ใช้กับตัวอ่านคลังฟิสิกส์/เคมี
=======================================================

อ่านไฟล์นี้ทั้งหมดก่อนสร้างหรือแก้ข้อสอบ ห้ามเดาว่าระบบรองรับ HTML ทุกชนิด
กติกานี้สำหรับ HTML ในคอลัมน์ C ของ Sheet ไม่ใช่แม่แบบ native Quiz ของ Hub
แม่แบบที่คัดลอกได้: sheet-question-template.txt ในโฟลเดอร์เดียวกัน
ตัวตรวจจริง: scripts/validate-bank-html.mjs ใน repository Nixcentury/learning-hub
แหล่งตัดสินสุดท้าย: question-bank-adapter.js, question-bank-svg.js,
quiz-content-adapter.js และ quiz-question-model.js ภายใต้ public/shared/
หากไฟล์เหล่านี้เปลี่ยน ต้องตรวจความเข้ากันได้ใหม่ ไม่อ้างคู่มือนี้แทนการทดสอบ

1. หน้าที่ของ AI และขอบเขต
--------------------------
สร้างเฉพาะโจทย์ ข้อมูลประกอบ ตัวเลือก คำใบ้ และเฉลย
ไม่สร้างระบบจับเวลา ตรวจคำตอบ บันทึกคะแนน ปุ่มเฉลย สมุด หรือปุ่มพิมพ์เอง
ไม่ใส่ script, event handler, iframe หรือ CSS/JavaScript ของเว็บไซต์
ไม่เปลี่ยน ID ชุด ลำดับข้อ เฉลย หรือค่าคลาดเคลื่อนของงานเดิมเอง
การตรวจโครงสร้างผ่านไม่ได้ยืนยันความถูกต้องทางวิชาการ ต้องตรวจแยกเสมอ

2. โครงข้อมูลใน Sheet
----------------------
A: ID เต็มของชุดข้อสอบ ต้องตรงกับชุดใน Sitemap
B: ID เต็มของหัวข้อเนื้อหา ใช้จัดหัวข้อและเชื่อมเนื้อหาทบทวน
C: HTML ข้อสอบตามรูปแบบด้านล่าง
ช่อง A หรือ B ที่ตรงกับชุดจะทำให้แถวนั้นเข้าชุด โดยนับแถวเดียวครั้งเดียว
แนะนำหนึ่งข้อในหนึ่งเซลล์ C; ระบบอ่านหลาย .question-step ต่อเซลล์ได้
ห้ามซ้อน .question-step ภายในอีกข้อ และห้ามใช้แถวว่างแทนข้อที่ยังไม่พร้อม
รหัสเซฟจริงสร้างจาก subject + bankKey + ลำดับข้อ ไม่ได้อ่านจาก id ของ input
ห้ามแทรก/ลบ/สลับข้อในชุดที่เผยแพร่โดยไม่วางแผนรุ่นข้อสอบกับผู้ดูแล
ห้ามเปลี่ยนข้อความ ID ใน A/B หรือ Sitemap เพื่อปรับชื่อสวย ๆ โดยพลการ
การแก้ HTML ทำให้ revision เปลี่ยน; งานที่เซฟไว้จะใช้รุ่นเดิมในคลังฉบับเก่า
ห้ามบังคับย้ายคำตอบเดิมไปลงโจทย์ที่เปลี่ยนแล้ว

3. ข้อเลือกตอบ
---------------
แต่ละข้อใช้ <div class="question-step" data-ans="B"> ... </div>
ต้องมี h3 ที่มีข้อความโจทย์ และ .options ที่มี radio 2–12 ตัว
ทุกตัวเลือกห่อด้วย label; input type="radio" และ value ไม่ซ้ำกัน
แนะนำ value="A" ถึง "E" ตามข้อสอบจริง; ไม่เพิ่มตัวเลือกเพื่อให้ครบตัวอย่าง
ระบบเทียบ value แบบตัวเล็ก; data-ans ต้องตรงกับ value ของคำตอบหนึ่งตัวเลือก
รหัสตัวเลือกที่รองรับ: ขึ้นต้น a-z ตามด้วย a-z, 0-9 หรือ - รวมไม่เกิน 16 ตัว
ใส่ข้อความที่มองเห็นในทุก label แม้ตัวเลือกนั้นเป็นรูปภาพ
ห้ามใช้แต่ภาพ เลขในภาพ หรือ aria-label แทนข้อความกำกับภายนอกภาพ
ไม่ใส่ checked/disabled หรือสร้างปุ่มตอบเอง; ให้ Engine ควบคุมสถานะ
หาก preview HTML ด้วย input name ให้ใช้ชื่อเฉพาะแต่ละข้อ ไม่ใช้ชื่อร่วมทุกข้อ

4. ข้อเติมตัวเลข
----------------
ใช้ .question-step ที่มี data-type="fill-in" และ data-ans เป็นค่าตัวเลข
ต้องมี input.num-answer เพียงหนึ่งช่อง ชนิด number หรือ text
วางช่องใน <div class="answer-section"> และไม่ใส่ .options หรือ radio
แนะนำ data-ans เป็นตัวเลขมาตรฐาน เช่น 50, -2, 6.70, 0.125
ไม่ใส่หน่วย comma สัญลักษณ์ = หรือวงเล็บ MathJax ใน data-ans
ตัวอ่านรองรับนิพจน์ตัวเลขแบบจำกัด แต่ห้ามพึ่ง eval หรือ JavaScript expression
data-tolerance เป็นตัวเลขตั้งแต่ศูนย์ขึ้นไป; ถ้าไม่ใส่เท่ากับ 0
ระบบไม่เดาค่าคลาดเคลื่อนจากจำนวนทศนิยม และไม่เดากฎเลขนัยสำคัญให้
ถ้าต้องยอมคลาดเคลื่อน ให้ผู้ดูแลกำหนดค่าก่อน ไม่เปลี่ยนเพื่อให้คำตอบผ่าน
หน่วยแยกไว้ใน data-unit-th และ data-unit-en เช่น mol, N หรือ years
Engine แทนช่องเดิมด้วยช่องคณิตกลาง ไม่ต้องแนบ MathLive หรือแป้นคีย์บอร์ด
ไม่รองรับข้อเขียนอิสระ หลายช่องคำตอบ หรือ drag/drop ผ่านสัญญา Sheet นี้
งานประเภทอื่นให้ใช้แม่แบบ native Quiz แยก ไม่ดัดแปลงด้วย data-type ที่คิดเอง

5. ตำแหน่งข้อความ ตาราง คำใบ้ และเฉลย
---------------------------------------
h3 แรกเป็นหัวโจทย์; ข้อมูล ตาราง หรือรูปหลัง h3 และก่อน .options เป็นบริบท
งานใหม่แนะนำ h3 เดียว แล้วใช้ p สำหรับคำสั่งต่อท้ายหลังตารางหรือรูป
ตัวอ่านรองรับ h3 เพิ่มเติมของงานเก่าและเก็บไว้ในบริบท ไม่ต้องลบข้อความนั้น
คำใบ้แต่ละส่วนอยู่ใน <div class="hint-box"> ใส่ได้มากกว่าหนึ่งส่วน
เฉลยและวิธีคิดอยู่ใน <div class="feedback-box"> เดียวต่อข้อ
อย่าวางเฉลยไว้นอก feedback-box เพราะอาจแสดงเป็นบริบทก่อนตอบ
ข้อเลือกตอบควรอธิบายเหตุผลและตัวลวงตามขอบเขตผู้ใช้; ข้อคำนวณแสดงขั้นและหน่วย
ไม่แก้เนื้อหาวิชา/ตัวเลข/คำตอบเมื่อได้รับงานให้แก้เฉพาะรูปหรือการจัดหน้า

6. HTML ที่แสดงผลได้
---------------------
ข้อความและแท็ก: p div span b strong i em u s sub sup br hr ul ol li
table thead tbody tfoot tr td th caption blockquote pre code h3 h4 h5 h6 img
td/th ใช้ colspan/rowspan เป็นจำนวนเต็ม 1–99 ได้
HTML style, class, id และ data-* ทั่วไปไม่ได้ถูกคัดลอกไปเป็นดีไซน์ของ Engine
ใช้ class/data-* เฉพาะส่วนที่คู่มือนี้กำหนดเป็นสัญญาข้อสอบ
อย่าพึ่งสี เส้นขอบ หรือความกว้างที่เขียนเป็น style ของ div/table/span
Engine จัดตัวอักษร ตาราง ปุ่ม และระยะพิมพ์เอง
รูป img ต้องเป็น URL เต็ม HTTPS ไม่มีชื่อผู้ใช้/รหัสผ่านใน URL
ต้องเป็นลิงก์ไฟล์รูปจริงที่เปิดสาธารณะได้ ไม่ใช้หน้า Drive viewer เป็น src รูป
ไม่ใช้ data:, blob:, file:, javascript: หรือ path ในเครื่องเป็น img src
ข้อยกเว้น data:image/svg+xml สร้างโดยตัวอ่านเองเท่านั้น ห้าม AI ฝังมาเอง
สื่อ canvas, iframe, object, embed, audio, video ต้องแปลงเป็นภาพหรือแยกเป็นเครื่องมือ

7. สูตรและภาษา
---------------
ใช้ MathJax: \(...\) หรือ $...$ สำหรับ inline; \[...\] หรือ $$...$$ สำหรับ display
ตัวอย่าง: \(E=mc^2\), \(\frac{n}{V}\), \(\mathrm{H_2O}\), \(\ce{H2O}\)
Engine มี MathJax และ mhchem ให้แล้ว ไม่แนบ CDN หรือ script เพิ่ม
ใช้ display เฉพาะสูตรหลัก ไม่ทำทุกค่าตัวเลขเป็นสมการขนาดใหญ่
ถ้าอยู่ใน JSON ให้ escape backslash ตาม JSON; ถ้าเป็น HTML ที่วางในเซลล์ใช้ backslash จริง
Sheet HTML ยังไม่ใช่สัญญาสลับภาษาเนื้อหาแบบ native Quiz
TH/EN ของ Engine เปลี่ยนภาษาเครื่องมือ ไม่ได้แปลหรือซ่อนย่อหน้าของโจทย์โดยอัตโนมัติ
ถ้าต้องการสองภาษาใน Sheet ให้ใส่ข้อความจริงทั้งสองภาษาอย่างเป็นระเบียบ
รูปประกอบแนะนำป้ายอังกฤษ; ไม่ใช้ข้อความ data-th/data-en แทนข้อความจริงในโจทย์

8. SVG: รูปแบบที่แนะนำสำหรับงานใหม่
-----------------------------------
สร้าง SVG ภาพนิ่งที่มี xmlns="http://www.w3.org/2000/svg"
ระบุ viewBox="0 0 W H" พร้อม width/height แบบตัวเลขที่มีอัตราส่วนตรงกัน
viewBox ต้องมีตัวเลข finite สี่ค่า ความกว้าง/สูงมากกว่า 0 ทุกค่ามีขนาดไม่เกิน 100000
ถ้าไม่มี viewBox ต้องมี width และ height เป็นตัวเลขบวก หรือ px
เปอร์เซ็นต์ width/height ใช้ได้เมื่อมี viewBox แต่แนะนำตัวเลขเพื่อขนาดภาพที่แน่นอน
ใช้ rect วาดพื้น/กรอบ; ใช้ g transform="translate(...) scale(...)" จัดพื้นที่ว่าง
ไม่ใช้ CSS ของหน้าเว็บเป็นตัววาดภาพ และไม่พึ่ง class/style block หรือ CSS variables
รูปต้องอ่านได้ในหน้าจอแคบและเมื่อพิมพ์ ข้อความ/หน่วย/หัวลูกศรห้ามทับกัน
ไม่แปลงเป็น raster เพื่อเลี่ยงข้อผิดพลาดโดยไม่แจ้ง; แก้ต้นเหตุในรูปก่อน

แท็ก SVG ที่รองรับครบ:
svg g defs symbol use path rect circle ellipse line polyline polygon text tspan
title desc marker clipPath linearGradient radialGradient stop

แอตทริบิวต์ทั่วไปที่รองรับ:
id viewBox preserveAspectRatio x y x1 y1 x2 y2 cx cy r rx ry width height d points
transform dx dy rotate textLength lengthAdjust markerWidth markerHeight refX refY
orient markerUnits marker-start marker-mid marker-end clip-path clipPathUnits
gradientUnits gradientTransform spreadMethod offset stop-color stop-opacity fx fy fr

Presentation attributes / inline style ที่รองรับ:
fill fill-rule fill-opacity stroke stroke-width stroke-linecap stroke-linejoin
stroke-miterlimit stroke-dasharray stroke-dashoffset stroke-opacity opacity color
vector-effect paint-order font-family font-size font-weight font-style text-anchor
dominant-baseline alignment-baseline letter-spacing word-spacing

use ใช้ href หรือ xlink:href ได้เฉพาะ #id ภายในภาพเดียวกัน
fill/stroke/clip-path/marker-* อ้าง url(#id) ภายในภาพได้เท่านั้น
id ขึ้นต้นตัวอักษรอังกฤษหรือ _ ตามด้วยตัวอักษร ตัวเลข _ . : - รวมไม่เกิน 101 ตัว
ห้าม id ซ้ำใน SVG เดียว; รูปคนละภาพใช้ id ซ้ำกันได้เพราะแยก image document
ทุก reference ต้องมีเป้าหมายจริง ห้ามวงจรหรือ use ที่อ้าง artwork ซึ่งมี use ซ้อนอยู่
ไม่อ้าง CSS สี ฟอนต์ ภาพ หรือ resource ภายนอกผ่าน SVG
ห้าม script, event handlers, foreignObject, image, animation, filter, style block และ class
ห้าม url ภายนอก, @import, expression(...), var(...) และ !important
ไม่ใช้ backslash หรือ < > ในค่าแอตทริบิวต์ SVG
ขอบเขตต่อรูป: 2000 elements, ข้อความ 20000 ตัว, ค่าแอตทริบิวต์ 50000 ตัว,
SVG หลังสร้างใหม่ไม่เกิน 250000 ตัวอักษร; ภาพเกินนี้ต้องย่อก่อน

ความเข้ากันได้กับ SVG เก่าที่มีกรอบ CSS:
เฉพาะ svg รากรับ style กลุ่ม width height max-width background background-color
border border-radius padding โดยต้องเป็นค่าคงที่ที่ตรวจแล้ว
length ใช้ค่าบวก/ศูนย์แบบ px % em rem pt หรือ 0 ไม่มีหน่วย ขนาดไม่เกิน 100000
width/height/max-width รับ auto ได้; สีพื้นต้องเป็นสีทึบ ไม่ใช้ gradient หรือ url
border ใช้ none หรือ ความหนา + solid/dashed/dotted/double + สีทึบ
padding/border-radius รับ 1–4 ค่า length; ไม่รับ property จัดตำแหน่งอื่น
ตัวอ่านย้ายกรอบกลุ่มนี้ไปที่ img และจำกัด max-width:100%, box-sizing:border-box
สำหรับงานใหม่ให้ใช้ pure SVG ตามแบบข้างต้น เพื่อใช้ร่วมกับเครื่องมืออื่นง่ายกว่า

9. ตรวจงานก่อนส่ง
------------------
ตรวจเนื้อหาวิชา หน่วย เงื่อนไข ตัวลวง และเฉลยกับต้นฉบับ/ผู้สอน
เทียบจำนวนข้อ ลำดับ ประเภทคำถาม และเฉลยก่อน/หลังทุกครั้งที่แก้งานเดิม
รันจาก root ของ repository:
node scripts/validate-bank-html.mjs path/to/draft.html --subject chemistry
node scripts/validate-bank-html.mjs path/to/snapshot.json
--bank-key b-... ใส่ได้เมื่อทราบรหัสจริง; ค่าเริ่มต้นเป็นรหัสทดสอบ ไม่ใช้เผยแพร่
snapshot.json รับทั้งตัว snapshot และผล API ที่มี {"ok":true,"data":...}
คำสั่งนี้ทำงานออฟไลน์ ไม่แก้ Sheet ไม่เผยแพร่ และไม่แตะข้อมูลนักเรียน
ผ่านตัวตรวจแล้วต้องเปิดกับ Engine จริง: รูปทุกภาพต้อง decode และแสดงครบ
ตรวจรูปในโจทย์ ตัวเลือก คำใบ้ และเฉลย แยกกัน ไม่ตรวจเฉพาะข้อแรก
ตรวจบนมือถือ/แท็บเล็ต: รูป ตาราง สูตร และปุ่มต้องไม่ถูกตัดหรือทับกัน
ตรวจพิมพ์ชุดเปล่าและเฉลย: จำนวนข้อครบ ชุดเปล่าไม่แสดงเฉลย ภาพเฉลยอยู่ฉบับเฉลย
ตรวจเปลี่ยนภาษา บันทึก ปิด/เปิดใหม่ และรุ่นโจทย์เดิมโดยไม่ล้างข้อมูลเว็บไซต์
ห้ามรายงานว่า QA ผ่านส่วนที่ยังไม่ได้ทดสอบจริง โดยเฉพาะ iPad/Apple Pencil/Cloud

10. สิ่งที่ AI ต้องส่งกลับ
--------------------------
1) HTML ข้อสอบหรือไฟล์ที่แก้ พร้อมตำแหน่งเซลล์/ไฟล์ที่ชัดเจน
2) จำนวนข้อ ประเภท เฉลย และค่าคลาดเคลื่อนที่ตรวจแล้ว
3) รายการเปลี่ยนแปลง โดยระบุว่าเปลี่ยนเนื้อหา/คำตอบหรือเฉพาะรูปแบบ
4) ผลตัวตรวจและผล Browser/Print ที่ทำจริง พร้อมข้อที่ยังไม่ได้ตรวจ
5) ถ้าติด SVG ให้ระบุแถว/ข้อ/แท็กหรือ style ที่ติด ไม่ข้ามรูปหรือข้อเงียบ ๆ
ห้ามนำรูปที่เปิดไม่ได้ออกแล้วกล่าวว่าข้อสอบครบ หรือแก้เฉลยเพื่อให้ตัวตรวจผ่าน
