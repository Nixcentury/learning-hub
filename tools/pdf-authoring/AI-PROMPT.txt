งานนี้อยู่ใน https://github.com/Nixcentury/learning-hub
ใช้แม่แบบ PDF กลาง v1.0 A4 แนวตั้งที่มีอยู่แล้ว เพื่อให้ PDF จาก AI ทุกตัวมีหน้าตาเดียวกัน

อ่าน START-HERE.txt, PDF-AUTHORING-START-HERE.md และ tools/pdf-authoring/README.md ก่อนเริ่ม
อ่านโจทย์และขอบเขตเนื้อหาที่ผู้ใช้มอบหมายให้ครบ ห้ามเพิ่มหัวข้อเกินใบเรียนรู้หรือข้อสอบเป้าหมายโดยพลการ

วิธีทำ:
1. คัดลอก tools/pdf-authoring/starter เป็นโฟลเดอร์เนื้อหาใหม่ ใช้ id ใหม่ที่สื่อความหมาย
2. แก้เฉพาะ metadata.json, content.html และ assets/ ในโฟลเดอร์นั้น
3. ทำเนื้อหา TH/EN ต่อเนื่อง ครบ และลำดับตรงกัน คง question IDs เมื่อแก้งานเดิม
4. ฉบับนักเรียนเน้นพื้นที่จดและทำโจทย์ กำหนด data-pdf-space ให้เหมาะกับวิธีทำ
   เฉลยเต็มอยู่ใน data-pdf-answer ของข้อเดียวกัน มีหน่วย เหตุผล และการปัดเศษ
5. ถ้าเป็นเคมี: กรด/เบสแก่ใช้ ICF แถว C ตามเลขดุล กรด/เบสอ่อนใช้ ICE
   จัดข้อมูลเป็น mol หรือ mol/L ให้หน่วยในตารางตรงกันก่อน เน้นตัวคูณแปลงหน่วยที่แสดงการตัดหน่วย
   กำหนดสมมติฐานและตรวจเงื่อนไขการประมาณ สมการใช้ MathJax/mhchem ตามคู่มือ
6. ผลิตผ่าน tools/pdf-authoring/render.mjs และ render_pdf.py เท่านั้น ตามคำสั่งใน README
   เลือกภาษาและฉบับตามที่ผู้ใช้ขอ ไม่จำเป็นต้องผลิตทุกฉบับในทุกงาน
7. ตรวจเนื้อหาและคำตอบทุกข้อ รัน pnpm test:pdf:authoring
   เปิดดูภาพที่ render จาก PDF ทุกหน้า ตรวจอักษรไทย สมการ ตาราง ช่องทำ หัว-ท้ายและเลขหน้า
8. ส่ง PDF + ต้นฉบับ + report ระบุรุ่นแม่แบบ จำนวนหน้า และผล QA ตามจริง
   ทำ PR เมื่ออยู่ในงาน repo ที่ได้รับคำสั่งให้ส่ง PR ไม่ merge เอง

ข้อห้ามเรื่องรูปแบบ:
- ห้ามออกแบบหน้ากระดาษใหม่ เปลี่ยนเป็น A3/แนวนอน ลดฟอนต์ หรือเพิ่มธีมสี
- ห้ามแก้ master.css, fonts.css, renderer, dependency versions, template.lock.json เพื่อให้งานชิ้นนี้ผ่าน
- ห้ามใส่ style/script/header/footer เองใน content.html หรือคัดลอก master ไปดัดแปลง
- ห้ามเปลี่ยนไปผลิต PDF ผ่าน Word, ReportLab, browser print หรือ engine อื่นแล้วอ้างว่าใช้แม่แบบนี้
- ถ้าผลิตไม่ได้ ให้ส่งต้นฉบับและบอกข้อจำกัด ไม่อ้างว่าได้ตรวจ PDF แล้ว
- ห้ามสร้างจอ PDF ใหม่ในบทเรียน ใช้ระบบเดิมตาม PDF-VIEWER-START-HERE.md

การเชื่อม Drive:
หลังตรวจ PDF แล้ว ผู้ใช้จะให้ลิงก์จริงหรืออัปโหลดเอง
ใช้ data-pdf-common / data-pdf-th / data-pdf-en บนปุ่มเดิม ช่องยังไม่มีไฟล์ปล่อยว่าง
ห้ามแต่งรหัส Drive ลิงก์ตัวอย่างหรือ URL ปลอมในไฟล์ที่จะ build
แยกปุ่มฉบับนักเรียนกับเฉลย ไม่ใช้ลิงก์เฉลยเป็น fallback ของนักเรียน
ไม่เปลี่ยนสิทธิ์ Drive ไม่อัปโหลดหรือเผยแพร่เอกสารส่วนตัวเอง
