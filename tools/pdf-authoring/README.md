# แม่แบบ PDF กลาง Learning Hub v1.0

แม่แบบเดียวสำหรับ PDF ใหม่ของครูนิค ใช้ A4 แนวตั้ง ฟอนต์ฝังในไฟล์ และหัว-ท้ายกระดาษรูปแบบเดียวกันทุกงาน ให้ AI เปลี่ยนเฉพาะเนื้อหา ไม่ออกแบบเอกสารใหม่เอง

จอ PDF กลางแสดงไฟล์ที่ได้รับ ไม่ได้ใส่หัว-ท้ายกระดาษหรือแปล PDF ให้ ต้องสร้างไฟล์ให้เรียบร้อยก่อนอัปโหลด Drive แม่แบบนี้เป็นเครื่องมือผลิตเอกสารนอกเว็บ ไม่เพิ่มตัวแสดงผลอีกชุด ไม่เปลี่ยน PDF เก่า และไม่เปลี่ยนใบเรียนรู้ 10.3 บนเว็บ ตัวอย่างเคมีในโฟลเดอร์ examples มีไว้ตรวจรูปแบบเท่านั้น

## มาตรฐานที่ตรึงไว้

| รายการ | มาตรฐาน |

| ท้ายกระดาษทุกหน้า | ชื่อเอกสารและฉบับ / หน้า N จากทั้งหมด / Nix-century |
| ขอบนอกหัว/ท้าย | 12 mm; พื้นที่เนื้อหาเริ่ม 26 mm จากขอบบนและล่าง |
| ฟอนต์ | Hub PDF Thai + Hub PDF Latin, ฝังใน PDF; ดัดแปลงชื่อจาก Noto ตาม OFL |

| ฉบับนักเรียน | ลบคำตอบของข้อฝึกออกจริง เหลือพื้นที่เขียน |

## ส่งอะไรให้ AI ตัวต่อไป

ให้ลิงก์ repo พร้อม [AI-PROMPT.txt](AI-PROMPT.txt) และระบุเรื่อง/ระดับชั้น/ขอบเขตงาน

AI คัดลอก [starter](starter) เป็นโฟลเดอร์เนื้อหาใหม่ แล้วแก้เพียง:

1. `metadata.json`: id, วิชา, บท, หัวข้อ, ชื่อเรื่อง, คำอธิบายสั้น และชื่อเอกสาร TH/EN
2. `content.html`: เนื้อหา TH/EN ครบ ข้อฝึกและเฉลยในต้นฉบับเดียวกัน
3. `assets/`: รูปประกอบ SVG/PNG/JPEG ภายในโฟลเดอร์เนื้อหานั้น

ห้ามแก้ master.css, fonts.css, renderer หรือ template.lock.json เพื่อให้งานใดงานหนึ่งผ่าน ห้ามสร้าง CSS/ฟอนต์/header/footer เองหรือแปลงด้วย Word, ReportLab หรือเครื่องมืออื่นแทนเส้นทางกลาง ไฟล์ล็อกตรวจ SHA-256 ของแม่แบบก่อนผลิตทุกครั้ง หากแม่แบบหรือส่วนกลางเปลี่ยน ต้องทบทวนมาตรฐานและ QA ใหม่เป็นงานเฉพาะ ไม่อัปเดต hash เพื่อหลบข้อผิดพลาด

## ติดตั้งและผลิต PDF

ใช้ Node >=24 และ Python >=3.10 ติดตั้ง dependency โครงการตาม START-HERE.txt ก่อน จากราก repo:

```sh
npm ci --prefix tools/pdf-authoring
python3 -m venv tools/pdf-authoring/.venv
tools/pdf-authoring/.venv/bin/python -m pip install -r tools/pdf-authoring/requirements.txt
```

WeasyPrint ต้องใช้ Pango ตาม [คู่มือติดตั้งทางการ](https://doc.courtbouillon.org/weasyprint/v66.0/first_steps.html#installation) บนเครื่องนั้น ฟอนต์เอกสารอยู่ใน repo แล้ว ไม่ดาวน์โหลดฟอนต์ตอนผลิต หากพบอักขระที่ต้องใช้ฟอนต์สำรองนอกแม่แบบจะหยุดผลิต ให้ใช้ข้อความที่รองรับหรือเขียนสัญลักษณ์เป็น MathJax บน Windows ให้ตั้ง `HUB_PDF_PYTHON` เป็นเส้นทาง Python ใน venv ของเครื่องนั้น

```sh
HUB_PDF_PYTHON=tools/pdf-authoring/.venv/bin/python pnpm pdf:render \
  --input tools/pdf-authoring/examples/ionization \
  --out tools/pdf-authoring/output --language th --edition student
```

เปลี่ยน `--language` เป็น `en` และ `--edition` เป็น `teacher` ตามฉบับที่ต้องการ ทั้งหมดใช้แม่แบบเดียวกัน ไม่จำเป็นต้องส่งออกสี่ฉบับทุกงาน ถ้าผู้ใช้ต้องการสองภาษาในหน้าเดียว ให้ตกลงรูปแบบเนื้อหาเพิ่มก่อน ไม่สร้างแม่แบบใหม่เอง

ได้ `id-language-edition.pdf`, HTML ที่ใช้ผลิต และ `.report.json` ระบุจำนวนหน้า engine รุ่นแม่แบบ hash และ question IDs ใช้รายงานคู่กับ PDF ที่ SHA ตรงกัน

หากไม่มี dependency หรือผลิตไม่ได้ ให้ส่งต้นฉบับพร้อมข้อจำกัดตามจริง ห้ามสร้าง PDF ด้วย engine อื่นแล้วอ้างว่าเป็นมาตรฐานเดียวกัน

## สัญญาของเนื้อหา

metadata มีได้เฉพาะ `templateVersion`, `id`, `subject`, `chapter`, `topic`, `title`, `subtitle`, `work` ดู starter ทั้งหกช่องข้อความต้องมี `{ "th": "...", "en": "..." }` id ใช้อักษร a-z/0-9/- เริ่มด้วย a-z และคงเดิมเมื่อปรับเนื้อหา หัวกระดาษต้องสั้นพอหนึ่งบรรทัด ถ้ายาวให้ย่อชื่อ ไม่ลดฟอนต์

```html
<main data-pdf-content>
  <section data-content-lang="th" lang="th">
    <h2>1. หัวข้อเนื้อหา</h2>
    <p>คำอธิบายต่อเนื่อง ใช้ \(n=cV\) สำหรับสมการในบรรทัด</p>
    <div data-pdf-question="q-1" data-print-keep>
      <h3>คำถาม 1</h3>
      <p>โจทย์ที่มีข้อมูลครบ</p>
      <div data-pdf-space="40"></div>
      <div data-pdf-answer><p>วิธีทำและคำตอบพร้อมหน่วย</p></div>
    </div>
  </section>
  <section data-content-lang="en" lang="en">
    <!-- เนื้อหาอังกฤษครบ และ question IDs ตรงกับ TH ตามลำดับ -->
  </section>
</main>
```

- ชื่อเรื่อง คำอธิบายใต้ชื่อ และช่องชื่อ/ชั้น/วันที่ สร้างจาก metadata อัตโนมัติ ไม่ใส่ h1 ซ้ำใน content
- ใช้ h2-h4, p, ul/ol/li, table/caption/thead/tbody/tfoot/tr/th/td, figure/img/figcaption และ strong/em/sub/sup/span/a/br/blockquote ได้
- คำอธิบายตัวอย่างใช้ `class="pdf-example"`; หมายเหตุใช้ `class="pdf-note"` เท่านั้น ไม่มี class สี/ขนาด/ธีมให้เลือก
- สมการแสดงแยกบรรทัดใช้ `\[...\]`; เคมีใช้ `\ce{...}` ภายในสมการ ไม่โหลด MathJax เอง ไม่ใช้ macro ปรับฟอนต์หรือ external package
- ข้อฝึกแต่ละข้อมี question id ไม่ซ้ำ พร้อมคำตอบหนึ่งส่วนและพื้นที่เขียนหนึ่งส่วน ความสูง 16-80 mm นักเรียนไม่เห็นส่วน data-pdf-answer ใน PDF/HTML ที่ผลิตแล้ว
- `data-print-keep` เก็บเนื้อหาชุดสั้นไว้หน้าเดียว ข้อฝึกเก็บโจทย์กับพื้นที่ทำ/เฉลยไว้ด้วยกัน ถ้าสูงเกินหน้าให้แบ่งข้ออย่างมีความหมาย ไม่บีบตัวหนังสือ
- ตารางเก็บคำบรรยายและแถวทั้งหมดไว้หน้าเดียว ถ้ายาวเกินหน้าให้แบ่งตารางอย่างมีความหมาย ใช้ thead และ scope ที่ถูกต้อง แถว C ที่ต้องการเน้นใช้ `<tr data-pdf-change>` ไม่เขียน inline style
- รูปใช้พาธภายใน input เช่น `assets/figure.svg` พร้อม alt, width, height; ระบบฝังรูปก่อนผลิต ห้าม URL รูปภายนอก/payload/script
- ลิงก์อ้างอิงในเนื้อหาต้องเป็น HTTPS จริง; ไม่ดึงไฟล์หรือฟอนต์ภายนอกระหว่าง render
- ไม่รับ style/script/iframe/forms/header/footer, event handler หรือโครง html/head ซ้อน

## QA ก่อนส่งงาน

```sh
pnpm test:pdf:authoring
```

จากนั้นผลิต PDF ทุกฉบับที่ส่ง ตรวจขนาด A4 จำนวนหน้า ข้อ/คำตอบตรงภาษา ฟอนต์ฝังในไฟล์ และ render ทุกหน้าเป็นภาพด้วย `pdftoppm -png document.pdf page` เปิดดูทุกภาพจริง ตรวจสมการ อักษรไทย ตาราง หัว-ท้าย เลขหน้า ช่องเขียน การชน/ตัดขอบและพื้นที่ว่าง ส่วนเฉลยตรวจวิธีคิด หน่วย การปัดเศษ และคำตอบทีละข้อด้วย อย่าใช้แค่การดึงข้อความแทนตรวจภาพ

การแก้เฉพาะเนื้อหาไม่ต้องรัน browser suite ทั้งเว็บ ถ้าแก้จุดเชื่อมต่อ viewer ให้รัน `pnpm test:pdf` และ `pnpm build` เพิ่มด้วย รายงานเฉพาะสิ่งที่ทดสอบจริง ไม่อ้างว่าผ่าน iPad หรือสิทธิ์ Drive หากไม่ได้ตรวจ

## เปิดจาก Drive ในจอ PDF กลาง

ทำได้ เมื่อผลิต PDF เสร็จและตรวจแล้ว อัปโหลดเข้า Drive ตั้งสิทธิ์ผู้เรียนตามต้องการ แล้วใส่ลิงก์ `/file/d/.../view` จริงบนปุ่มของบทเรียน ตาม [PDF-VIEWER-START-HERE.md](../../PDF-VIEWER-START-HERE.md)

```html
<button type="button" data-hub-pdf data-content-id="new-stable-pdf-id"
  data-pdf-common="" data-pdf-th="" data-pdf-en=""
  data-th="เปิดเอกสาร" data-en="Open document">เปิดเอกสาร</button>
```

ปล่อย URL ว่างจนมีลิงก์จริง ใช้ data-pdf-th/en สำหรับฉบับภาษา ใช้ data-pdf-common สำหรับไฟล์ร่วม จอเดิมจะเลือกไฟล์ตามภาษา ไม่แปลเนื้อหา PDF และไม่ปรับ layout ใหม่ ถ้าใช้ฉบับนักเรียนและเฉลยให้ทำคนละปุ่ม/รายการ ไม่ใส่เฉลยเป็น fallback ของฉบับนักเรียน

ไฟล์ที่ไม่มีสิทธิ์ยังเปิดไม่ได้ตามสิทธิ์ Drive เดิม แม่แบบไม่อัปโหลด ไม่เผยแพร่ และไม่เปลี่ยนสิทธิ์ไฟล์ให้เอง
